## ⚠️ 待驗證項目

以下是規格中**推導但未實測**的部分，P1 蒙地卡羅階段必須複驗（見 [08 P1](08-roadmap.md#p1--規則引擎--最重要的階段)）：

| # | 項目 | 風險 |
|---|---|---|
| 1 | 🔴 **預期約 21 圈是否放大起手優勢** | 一格地 2.3 圈回本 × 約 18 圈獲利期，複利可能失控——與「日常型是翻身主場」的意圖相反 |
| 2 | 🔴 **組隊者 vs 單身者勝率差距 < 8pp** | 家庭系統的核心風險 |
| 3 | 🔴 **日常型車輛是否還有意義** | 固定擲骰下，車輛價值改為落點選擇權，需驗證是否值得持有成本 |
| 4 | 🟡 認購溢價是否有效抑制富人碾壓 | 全新機制，完全未驗證 |
| 5 | 🟡 進修 vs 購地的平衡 | 進修成功時 $1.20M、期望約 $0.60M vs 買地 $1.06M；需驗證 50% 打水飄風險是否過重 |
| 6 | 🟡 `SEC_PER_TURN = 12` 是否準確 | **所有即時配對型時長預測的基礎**，P2 熱座必測 |
| 7 | 🟡 30 人局是否仍需「起始現金 × 1.3」 | 棋盤已從 28 放大到 35 格地產 |
| 8 | 🟡 監獄／醫院頻率是否過低而無感 | 期望每年 0.16 / 0.27 次 |
| 9 | 🟡 金融業私人放貸是否過度影響破產率 | 金融業可拒貸，需模擬退場速度 |
| 10 | 🟡 股票佔勝者資產的比重是否合理 | 目標 10–30% |

**前三項是「節奏重構」引入的新風險**，第一版沒有。共同成因：改制改變了時間尺度（7 圈 → 預期約 21 圈）與移動語意，使原本的平衡推導失效。

### 已在推演中發現並修正的問題

| 問題 | 修正 |
|---|---|
| 固定資產門檻低於「富裕家庭 + 工程師」的**起始**資產 | 加入 `max_starting_net_worth × 1.6` 下界 |
| M 值制無法同時服務 2 圈與預期約 21 圈的局 | 改為 `(開局身家 + 預期圈數 × 季薪) × 2.5`，自動縮放 |
| 固定抽樣約束在 10 格地產的小棋盤上**無解** | 約束集改為隨地產格數縮放（[03 §3.3](03-map-system.md#33-抽樣約束隨棋盤縮放)） |
| 「輪（Round）」在非同步下失去意義 | 局長單位改用**天**，個人進度用**圈** |
| 事件流的 `claim` 與保險理賠撞名 | 認購事件改用 `bid_*`，表名保留 `property_claims` |

完整推演見 [02 §11](02-game-balance.md#11-可玩性推演)。
