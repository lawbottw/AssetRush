## 0. v1 範圍

M1 已切割 v1 範圍（issue #7）。**砍掉的東西不是刪除，是延後**——規格完整保留在本文件中，只標記為 `🔜 v1.1`，`config/` 對應條目設 `enabled: false`。v1.1 要啟用時把旗標改回 `true` 即可，不必重寫規格。

### 切割判準：需不需要**新機制**，而不是有幾個選項

M1 的 Config 驅動架構（Effect Registry + 公式求值器）讓**同機制的變體幾乎免費**——四種保險共用一個查表 handler，砍成兩種省不到程式碼。真正貴的是新的機制路徑：新的監控迴圈、新的狀態追蹤、新的結算階段。

| 系統 | v1 | 判準 |
|---|---|---|
| 地產、股票、交易、職涯、進修、監獄／醫院 | ✅ | 核心 |
| [家庭系統](#17-家庭系統情侶結婚家庭)（四個 tier 完整） | ✅ | 完整保留 |
| [保險](#11-保險系統)（4 險種） | ✅ | 共用一個查表 handler，事件卡的 `category` 標籤已存在 |
| [車輛](#10-車輛系統)（兩種模式） | ✅ | 系統共用，日常型的價值由 M3 驗證回答 |
| 貸款：信用／房貸／學貸／金融業私人放貸 | ✅ | 共用同一條借款→計息→還款路徑 |
| 副業：網拍／團購／接案／收租代管 | ✅ | 都是「每圈收益」的變體 |
| **[貸款：股票質押](#122-貸款產品)** | 🔜 **v1.1** | 唯一有追繳機制，需要每回合監控持股市值並可能觸發強制賣出 |
| **[副業：直銷](#94-副業)** | 🔜 **v1.1** | 唯一需要 NPC 下線追蹤，且綁事件卡 O12 |

**連帶移除**：機會卡 **O12「拉到下線」**（`requires_side_job: mlm`，沒有直銷就是永遠不觸發的死卡）。issue #8 補入 O23「創業合夥邀約」後，機會卡仍維持 22 張、權重總和 100。

## 1. 名詞定義

| 名詞 | 定義 |
|---|---|
| **局（Game）** | 一次完整的遊戲。由一個 LINE 群組或配對系統建立，2–30 人，結束後不留下任何跨局資產。 |
| **回合（Turn）** | 即時配對型：一位玩家擲骰並行動一次。日常型：一位玩家走完當日一整圈。 |
| **圈（Lap）** | 從起點出發並再次通過起點。**遊戲內 1 圈 = 1 季（3 個月）**，4 圈 = 1 年。通過起點領季薪並開啟[季度事務](#18-季度事務)。 |
| **天（Day）** | 日常型的局長單位。每天有固定擲骰額度；**通過起點才算 1 圈 = 1 季**，全局 21 天。 |
| **格（Tile）** | 棋盤上的一個位置。格數依模式與人數而定（即時配對型 16–32、日常型 28/36/48）。 |
| **地產格（Property Tile）** | 對應一個台灣鄉鎮市區、可購買的格。約佔全盤 70–75%。 |
| **功能格（Function Tile）** | 起點、機會、命運、休閒、稅捐、監獄、醫院。**共 7 種**。 |
| **基價（Base Price）** | 一個地產格的購買價，由該鄉鎮真實成交均價換算而來。租金、升級成本、貸款額度皆以此為基準。 |
| **認購（Claim）** | 日常型的購地方式：出價登記，每日 00:00 仲裁（見 [§6.3](#63-出價認購日常型)）。 |
| **季度事務（Quarterly Affairs）** | 通過起點時開啟的財務結算畫面。股票、貸款、進修、買車、保險全在此辦理。 |
| **健康（Health）** | 0–100 的狀態值，影響每圈健康檢定。休閒、旅遊、健檢可提高；疾病、住院、過勞可降低。 |
| **運氣（Luck）** | 開局決定的輕量狀態，影響機會／命運抽卡的微小權重，不影響骰點、股票價格或認購仲裁。 |
| **總資產（Net Worth）** | 現金（含凍結現金） + 地產市值 + 股票市值 + 車輛殘值 − 負債。**認購溢價不計入。** |
| **Standing Orders** | 玩家預先設定的自動決策規則，於當日未行動時執行。 |

> **「輪（Round）」一詞已廢除。** 日常型改為非同步後，不再有「全桌各動一次」的同步概念——局長單位是**天**，個人進度單位是**圈**。

## 2. 局的生命週期

```
建立 (lobby)
   │  房主設定：模式、結束門檻、是否公開
   ↓
報名 (recruiting)
   │  2–30 人加入。房主可隨時開始，或到期自動開始
   ↓
開局 (starting)
   │  ① 產生 game_seed → ② 依模式/人數決定棋盤尺寸 → ③ 抽樣生成棋盤
   │  ④ 每人抽身分 → ⑤ 決定回合順位 → ⑥ 計算資產門檻 → ⑦ 公布 hash(server_seed)
   │  ⑧ 立即檢查一次結束條件（防止有人開局即達標）
   ↓
進行中 (active)
   │  即時配對型：即時輪流，直到任一結束條件觸發
   │  日常型：每日循環（各自行動 → 00:00 結算），最多 21 天
   ↓
結算 (settling)
   │  清算所有資產、排名、公開 server_seed
   ↓
結束 (finished)
   │  生成戰報 → 可分享
```

v1 不允許開局後中途加入玩家。已開局的桌可觀戰、可被邀請下一局，但不能插入目前這局。理由是中途加入會同時影響認購順位、資產門檻、破產比例分母與棋盤土地供需；這不是一個單純的 UI 問題。M2 引擎先實作封閉局，未來若要支援中途加入，必須另開規格。

### 2.1 回合順位的決定

開局時，每位玩家由伺服器擲一次 1D100，**由大到小**排定順位。同分則以加入時間先者在前。

**兩種模式下「順位」的意義完全不同：**

| 模式 | 順位的作用 |
|---|---|
| 即時配對型 | **真正的輪流順序**。整局固定不變，破產者的位置直接跳過 |
| 日常型 | **僅為同價競標時的仲裁權**（見 [§6.3](#63-出價認購日常型)），且**每日輪替一位** |

日常型的每日輪替是必要的：如果順位固定，第 1 位玩家會在整整 21 天裡持續享有搶地的優先權，那是不可接受的結構性優勢。

### 2.2 骰子公平性保證（Commit–Reveal）

開局時伺服器產生一個 `server_seed`，並在局內公布其 `SHA-256` 雜湊值。整局所有骰子由

```
roll_n = HMAC-SHA256(server_seed, f"{game_id}:{turn_seq}:{player_id}") mod 6 + 1
```

決定。局結束時公開 `server_seed`，任何人可自行驗算每一次擲骰。

這解決的是「系統是不是偷偷讓我骰爛」的信任問題——在一個朋友之間玩、且有內購的產品裡，這個質疑一定會出現。

## 3. 開局：抽身分

每位玩家獨立抽家境、職業、健康與運氣，**互相獨立、不做配對修正**。

### 3.1 家境（Background）— 決定起始資產

決定起始現金，以及可能附帶的股票、地產或學貸。分為負債／普通／小康／中產／富裕五級，機率依台灣家庭財富分配的偏斜形狀設定（詳見 [02](02-game-balance.md#1-家境抽取)）。

**富裕家庭若抽到地產**：該地產必須是本局棋盤上的某一格，由系統隨機指派，且已標記為該玩家所有（等級 L0）。

### 3.2 職業（Occupation）— 決定月薪

決定每經過起點時領取的薪資，以及職業主技能（如網紅累積粉絲、工程師調整路線、金融業私人放貸）。

### 3.3 健康與運氣 — 決定事件傾向

開局時每位玩家取得兩個非金錢狀態：

| 狀態 | 開局範圍 | 影響 |
|---|---|---|
| 健康 | 通常 60–80，少數較低或較高 | 每圈健康檢定、住院風險、疾病費用 |
| 運氣 | 通常接近 0，少數偏高或偏低 | 機會／命運抽卡權重的微小偏移 |

健康與運氣不直接計入總資產。它們的作用是讓「同樣有錢的人」仍有不同人生風險，而不是再增加一個可直接換算成錢的屬性。

### 3.4 起始附帶資產

家境可附帶股票、地產、學貸或車輛：

- 中產家庭可能起手擁有一格中價地產。
- 富裕家庭可能起手擁有高價地產與股票。
- 小康以上有低機率起手擁有機車或國產車。
- v1 **不允許起手自帶保險**。保險必須在第一次季度事務主動購買，讓玩家明確做出風險管理選擇。

### 3.5 起手不對稱是刻意的

有人開局就是負債 −$300,000 的服務業，有人是富裕家庭的工程師。這在傳統大富翁裡不存在（大家都是 $1,500）。

我們刻意保留這個不對稱，因為它是這款遊戲**想說的話**：起跑線本來就不一樣。但為了讓遊戲仍然可玩，設計上有三道補償閥：

1. **低起點的向上斜率更陡**——服務業進修門檻最低，轉職到高薪職業的路徑最短。
2. **機會／命運卡對低資產者更有利**——部分事件卡的金額與玩家資產反向掛鉤（如「政府紓困」）。
3. **地產是主要致富路徑，不是薪水**——月薪最高與最低差 2.7 倍，但一格好地產的租金能抵好幾個月薪水。買得早比賺得多重要。

實測驗證見 [02-game-balance.md](02-game-balance.md#11-可玩性推演)。

## 4. 回合結構

**兩種模式的回合單位不同**，但共用同一組階段。

| | 即時配對型 | 日常型 |
|---|---|---|
| 一個回合 = | **擲骰一次** | **固定擲骰次數的一日行動** |
| 節奏 | 即時輪流，20 秒倒數 | 非同步，當日任意時間完成自己的擲骰額度 |

### 4.1 即時配對型：一擲一回合

```
① 擲骰 → ② 移動 → ③ 落點事件 → ④ 自由行動 → ⑤ 結束回合
```

輪到你時完成上述五步，回合權交給下一位。若途中通過起點，額外開啟[季度事務](#18-季度事務)側欄（**不阻塞**其他人，你可以在別人回合時慢慢處理）。

### 4.2 日常型：固定擲骰次數

```
每日行動 = 從你目前位置開始，依棋盤尺寸取得固定擲骰次數
```

```
① 擲骰 → ② 移動 → ③ 落點事件 ─┐
   ↑                          │  還有擲骰額度 → 繼續擲
   └──────────────────────────┘
                              │  擲骰額度用完
                              ↓
④ 自由行動 → ⑤ 今日結束
```

- **位置持續**，不重置到起點。今天走到起點後 3 格，明天就從那裡繼續
- 每日擲骰次數固定，依棋盤尺寸配置：28 格 8 次、36 格 10 次、48 格 14 次
- 沿途事件逐次結算；遇到無主地、休閒格、關係事件等需要選擇時才停下來
- 通過或停留起點時，**立即觸發季度事務**；今日不因此結束，剩餘擲骰額度仍可繼續使用

**為什麼改成固定擲骰次數：** 若每日行動以「走完一圈」為終點，擲出高點數的人會用較少落點完成同一圈，事件、住宿與購地機會都比低點數者少。固定擲骰次數讓每位玩家每天面對近似相同的事件量；是否通過起點則交給骰運，長期平均約為每日一圈。

**季度事務不再等於每日結束。** 日常型仍是非同步；玩家不需要等其他人完成。通過起點只是本日行動中的一個結算點，不是排隊邊界。

### 4.3 各階段細節

**① 擲骰**

- 基礎 1D6；持有車輛者可選擇停在 `骰點` 或 `骰點 + 1`
- 伺服器執行（見 [§2.2](#22-骰子公平性保證commitreveal)），前端只播放動畫
- **服刑或住院中**：不擲骰、不移動。服刑者仍可擲一次骰嘗試出獄

**② 移動**

- 沿棋盤順時針前進
- 移動途中不觸發任何格的事件，只在終點格觸發
- **通過或停留於起點 → 健康檢定 + 領季薪 + 開啟季度事務**

**③ 落點事件**

依落點類型執行，見[第 5 節](#5-落點類型)。

**④ 自由行動**

| 行動 | 條件 |
|---|---|
| 升級自己的地產 | 現金足夠；**不限升級哪一格**，也不需停在該格 |
| 抵押／贖回地產 | |
| 發起／回應交易邀請 | 對象為任一存活玩家 |
| 發起／回應關係邀請 | 情侶、結婚、加入家庭（見[第 17 節](#17-家庭系統情侶結婚家庭)） |
| 修改 Standing Orders | 隨時，不佔行動 |

**股票、貸款、進修轉職、買車、保險不在這裡** —— 全部移到[季度事務](#18-季度事務)。這讓自由行動階段只剩「地產與人際」兩件事，UI 大幅簡化。

**「不限升級哪一格」是刻意的。** 傳統大富翁要求你停在自己的地才能蓋房，這在日常型下太慢——你可能好幾天才回到自己的地。

**⑤ 結束回合／今日結束**

- 檢查結束條件
- 即時配對型：回合權交給下一位存活玩家
- 日常型：今日擲骰額度用完，等待 00:00 全體結算

### 4.4 收入結算的時機

第一版把收入結算放在回合開頭。改制後，**所有收入與扣款都移到通過起點時的季度事務**——因為「一圈 = 一季」，季度結算本來就該發生在季末。

| 每圈（＝每季）自動執行 | 每 4 圈（＝每年）額外執行 |
|---|---|
| 領季薪 | 年終獎金 |
| 副業收入 | 股息配發（持股市值 × 3.2%） |
| 貸款最低應繳（本金 5% + 利息） | 保險費扣繳 |
| 車輛養護費 | 車輛折舊（殘值 −25%） |
| 家用扣繳（若有家庭） | 家庭基金分潤 |
| 在學／服刑／住院狀態 −1 | |

若結算後現金為負，立即進入[清算流程](#124-現金為負時的處理順序)。

## 5. 落點類型

**功能格有 7 種**，其餘全是地產格（約佔全盤 65–75%）。健康事件不是格子，而是每次通過起點時的圈結算檢定。

| 功能格 | 數量（隨棋盤縮放） |
|---|---|
| 起點（＝季度事務） | 1 |
| 機會 | 1–4 |
| 命運 | 1–4 |
| 休閒 | 0–2 |
| 稅捐處 | 1–2 |
| 監獄 | 1 |
| 醫院 | 1 |

**證交所、監理站、進修中心三種格已全部移除。** 股票、貸款、進修轉職、買車、保險都改到[季度事務](#18-季度事務)辦理。

移除的理由有兩個：

1. **它們讓「能不能進修」變成運氣問題**——整局沒踩到進修中心，翻身路徑就被骰子封死了。
2. **棋盤應該只講一件事：移動與地產。** 理財是「回到起點坐下來檢視」的事，不是「走到某一格才能做」的事。

棋盤尺寸見 [02 §4.1](02-game-balance.md#41-棋盤尺寸)。

### 5.1 起點（Start）＝ 季度事務

- 通過或停留 → 領取**季薪**（月薪 × 3）並開啟[季度事務](#18-季度事務)
- 停留於此 → 額外獲得 $20,000 的「準時到位獎金」
- 日常型下，通過起點不會結束今日行動；剩餘擲骰額度繼續使用

> 一圈 = 一季，是讓「繞一圈的收入 ≈ 買下一格的成本」成立的關鍵設定。推導見 [02 §0.1](02-game-balance.md#01-時間單位一圈--一季)。

### 5.2 地產格（Property）

| 情境 | 結果 |
|---|---|
| 無主 | 可選擇購買／認購，或只住宿一晚 |
| 自己的 | 可選擇**升級**（若現金足夠） |
| 別人的（未抵押） | **支付住宿費／租金**給地主。金額依等級與壟斷狀態計算 |
| 別人的（已抵押） | 不收租 |
| **當日已被認購但未結算** | 仍視為**無主**——住宿費付給系統，且你可以加價競標 |
| 別人的（雙方合意） | 支付住宿費／租金**後**，可額外發起「就地收購」——出價買下該格，地主可拒絕 |

地產格一定要處理「今晚住哪裡」：

- **買下／得標**：支付購買價，並支付一筆交易住宿成本給系統。這筆錢代表搬遷、代書、稅費與當晚住宿，不計入地產市值。
- **不買，只住宿**：支付基價一定比例的住宿費給系統。
- **住在別人的地**：支付住宿費／租金給地主。這是地主的主要收入。
- **住在自己的地**：不付住宿費，可選擇升級。

**放棄購買時不進行流拍拍賣。** 傳統大富翁規則有「無人購買則公開拍賣」，我們移除它，因為那需要所有人同步回應。日常型的認購制本身就已經是一種拍賣，只是**非同步**的。

### 5.3 機會 / 命運

抽一張卡並立即執行。兩者的差異：

- **機會（Opportunity）**：偏正面。獎金、政府補助、消費券、學費補助、保費折扣、關係事件，也可以出現「可拒絕的高風險邀約」。**不放投資消息或內線消息**。
- **命運（Fate）**：偏風險與現實。罰款、交易爭議、天災、住宅火災、車禍、稅務稽查、監禁、裁員、減薪、市場衝擊、家庭事件。**不放一般疾病事件**。

部分命運卡可由**保險**抵銷（見[第 11 節](#11-保險系統)）。完整卡表見 [02](02-game-balance.md#5-機會與命運卡表)。

法律事件不做每圈隨機觸發，而是掛在命運卡與既有負面事件上。交易爭議、訴訟、罰單、追債、賠償與車禍責任都可能開啟法律流程。

法律流程：

- 玩家可選擇不委任律師，直接承擔法律流程結果。
- 其他玩家若是律師，可收取一次性 $80,000 服務費處理案件。
- 委任律師後，該法律流程的有利結果機率 +40%。
- 重大案件未委任律師時，可能面臨鉅額賠償，或依案件嚴重度停權：民事爭議 2 次、重大案件 5 次、刑事案件 10 次。
- 小額罰單也可委任律師，但律師費可能高於罰單本身，通常只有高額或連鎖風險時才合理。
- 律師不能替自己收服務費；若案件發生在律師自己身上，只能視為自行處理，不產生職業收入。

### 5.4 休閒格（Leisure）

休閒格代表看電影、餐廳、泡溫泉、酒吧／酒店等消費。踩到時必須支付一筆休閒費，並依格子標籤觸發附加規則：

| 類型 | 基本效果 | 附加規則 |
|---|---|---|
| 電影／餐廳 | 支付小額消費 | 情侶可選擇兩人一起參加或只有落點者參加 |
| 溫泉／旅行 | 支付中額消費 | 有機率獲得下次健康檢定風險降低 |
| 酒吧／酒店 | 支付中高額消費 | 若玩家持有車輛，必須選擇代駕或承擔酒駕檢定 |

情侶、已婚或家庭成員踩到休閒格時，落點者可邀請關係成員一起參加；被邀請者不消耗今日擲骰額度。若一起參加，費用由雙方或家庭基金分攤；若只有落點者參加，只扣落點者現金。

### 5.5 稅捐處（Tax Office）

依**總資產累進**課稅，稅金投入「國庫池」。

國庫池的用途：當任何玩家抽到「政府紓困」「消費券」類事件卡時，從國庫池支付。池空則該卡無效果。

這讓稅收在經濟上是**暫存而非銷毀**，維持零和信條。

### 5.6 監獄（Jail）

**走到監獄格本身無害——那是「探監」，什麼事都不會發生。** 只有命運卡會把你關進去。

服刑期間（即時配對型 1 回合、日常型 1–3 天）：

| 可以 | 不可以 |
|---|---|
| ✅ 收租（你的資產照常運作） | ❌ 擲骰、移動 |
| ✅ 交易地產、升級地產 | ❌ **通過起點 → 沒有季度事務** |
| ✅ 回應交易 offer | ❌ 領季薪、買賣股票、申請貸款、進修 |

**坐牢真正痛的地方是失去季度事務**，而不是薪水減半。你走不到起點，所以整段期間領不到季薪、不能調整持股、不能借錢周轉——被關的那幾天，你的財務完全凍結。

**提前出獄**：每個被跳過的回合仍可擲一次骰，**擲出 6 立即出獄**；或支付保釋金 `$20,000 × 剩餘回合`。

刑期：酒駕 2、詐騙 1、逃漏稅 3、內線交易 2（**即時配對型一律壓到 1 回合**——20–40 回合的局關 2 回合等於 10% 的遊戲直接消失）。

**設計意圖**：坐牢懲罰的是**時間與流動性**，不是資產。你的地照收租、股票照漲，只是你動不了、也調不動。

### 5.7 醫院（Hospital）

經過或走到醫院格 = **健康檢查**：支付 $5,000 給醫療體系，獲得「下次醫療理賠 +10%」。場上沒有醫療職業時支付給系統。醫院格不是純負面，但會讓醫療職業取得穩定收入。

住院（即時配對型 1 回合、日常型 1–2 天）由健康檢定、事故或特定命運卡觸發：

| 可以 | 不可以 |
|---|---|
| ✅ 收租 | ❌ 擲骰、移動 |
| ✅ 回應交易 offer | ❌ 交易地產、升級地產 |
| | ❌ **通過起點 → 沒有季度事務** |

**醫療險的價值全在這裡**：有保險 → 住院回合數**減半**（無條件捨去，最少 1 回合）＋ 醫療費理賠 80%。無保險住院 2 天＋全額自付，是遊戲中最痛的組合之一。

**自費提前出院**：支付 `$50,000 × 剩餘回合` 給醫療體系。有錢就能買回時間——很真實，也讓現金充裕的玩家多一個選項。

### 5.8 監獄與醫院的對照

兩者都是「跳過回合」，但懲罰結構刻意不同：

| | 監獄 | 醫院 |
|---|---|---|
| 收租 | ✅ | ✅ |
| 地產操作 | ✅ | ❌ |
| 季度事務 | ❌ | ❌ |
| 可用保險減免 | ❌ | ✅ 醫療險 |
| 可花錢提前結束 | ✅ 保釋金 | ✅ 自費出院 |
| 懲罰的是 | **流動性** | **沒保險** |

觸發頻率刻意壓低——一年（4 圈）期望住院 0.27 次、入獄 0.16 次。**跳過回合是遊戲中最不好玩的懲罰，它應該是記憶點而不是常態。**

### 5.9 v1 不設的格

免費停車格。它在傳統大富翁裡是「什麼都不會發生」的格，而我們的棋盤每一格都要為「台灣地名」讓路。

## 6. 地產系統

### 6.1 等級與租金

| 等級 | 名稱 | 升級成本 | 停留租金 |
|---|---|---|---|
| L0 | 素地 | — | 基價 × 6% |
| L1 | 套房 | 基價 × 50% | 基價 × 15% |
| L2 | 公寓 | 基價 × 70% | 基價 × 30% |
| L3 | 大樓 | 基價 × 100% | 基價 × 55% |
| L4 | 商辦／飯店 | 基價 × 150% | 基價 × 90% |

升級必須**逐級進行**，不可跳級。升級不需停在該格，也不限升級哪一格。

**購地與升級皆可選擇「以房貸支付」**，當場開立一筆房屋抵押貸款（見 [§12.2](#122-貸款產品)）。

### 6.2 購地方式依模式分岔

| 模式 | 購地 | 為什麼 |
|---|---|---|
| 即時配對型 | **立即成交** | 即時嚴格輪流，同一時間只有一人決策，不可能衝突 |
| 日常型 | **出價認購** | 非同步行動下，兩人可能在同一天走到同一塊無主地 |

### 6.3 出價認購（日常型）

**這是整個日常型設計的樞紐。**

移動、付租金、抽卡、領薪、升級自己的地——這些全都是**可交換的**（誰先誰後結果都一樣）。真正不能並行的**只有一件事**：兩個人搶同一塊無主地。

不必為了那一件事，把 30 個人排成一列。

```
你走到無主地 → 出價認購（≥ 基價，現金當場凍結）
             ↓
       當日 00:00 結算
             ↓
   同格最高價得標 · 同價則當日順位在前者勝 · 落選全額退款
```

| 規則 | 內容 |
|---|---|
| 最低出價 | 基價 |
| 出價時 | 現金**凍結**（不可再用於其他認購或交易） |
| 結算前該格狀態 | 仍為**無主**——別人走到不付租金，且可加價競標 |
| 可見資訊 | **全部公開**：有幾人認購、目前最高價、出價者是誰 |
| 落選 | 全額退款 |
| 每日出價次數 | 不設上限（現金凍結本身就是限制） |

若認購者在 00:00 仲裁前進入清算或破產，該玩家所有待結算認購**立即取消並解凍現金**。若取消後該格沒有其他出價者，維持無主；若仍有其他出價者，照原規則由剩餘最高價得標。得標後才破產則地產先成交入帳，再依破產清算處理，避免同一事件有兩種時間線。

#### ★ 溢價是純沉沒成本

**認購溢價不計入市值、不影響租金、不計入貸款額度。** 租金、抵押、市值一律依**基價**計算。

這是整個機制的平衡核心——加價會自然收斂，不會演變成有錢人無限碾壓。而且它是零和信條的延伸：**多付的錢沒有變成資產。**

溢價也**不可貸款**，銀行只認基價。想加價搶地就得掏現金。

#### 順序感沒有消失，而是變了形

順位不再是「排隊等輪到我」，而是「同價時的仲裁權」，且**每日輪替**。

實際體驗是這樣的：

```
你走到 鹿港鎮（無主 · 基價 $72,000）
⚠ 阿宏今天已出價 $72,000
你的出價：[ $79,000 ]
```

**互動反而比排隊更強。** 你看得到誰在搶、搶多少，並當場決定要不要加價——這比「等 19 個人動完才輪到我」有張力得多，而且很真實，房市本來就是這樣競標的。

### 6.4 區域壟斷

地產格依所屬**縣市**分組。若一位玩家持有某縣市在本局棋盤上的**全部**地產格，該縣市所有地產租金 **×2**。

抵押其中任一格會暫時失去壟斷加成。

壟斷判定只看**未抵押且仍可收租**的地產。抵押中的地產仍屬於該玩家、仍計入總資產，但在壟斷判定中視為缺口；贖回後若條件重新滿足，壟斷加成立即恢復。

以縣市而非六大區域作為壟斷單位，是因為同縣市通常只有 2–5 格（見 [03](03-map-system.md) 的抽樣約束），達成難度剛好；若用六大區域，一組要 4 格以上，太難。

### 6.5 抵押與贖回

| 操作 | 金額 |
|---|---|
| 抵押 | 取得**基價 × 50%** 現金 |
| 贖回 | 支付**基價 × 55%**（含 10% 利息） |

抵押中的地產：不收租、不可升級、不計入壟斷、但**仍計入總資產**（以抵押後淨值計算）。

> **「抵押」與「房屋抵押貸款」是兩回事**，容易混淆。對照見 [§12.2](#122-貸款產品)。

### 6.6 地產持有稅

每次通過起點進行收入結算時，玩家需為名下地產支付**持有稅**：

| 項目 | 規則 |
|---|---|
| 稅率 | 每圈市值 0.5% |
| 稅基 | `base_price + invested`，不含認購溢價 |
| 對象 | 所有名下地產，包含已抵押或作為房貸擔保的地產 |
| 收款方 | 國庫 |

0.5%/圈約等於 2%/遊戲年（4 圈）。這個數字足以讓囤地有持有成本，但仍低於多數地產的租金收益，不會把買地主線打壞。

### 6.7 市值與出售

- **市值** = 基價 + 已投入的升級成本總額（不折舊）。**認購溢價不計入。**
- **賣回銀行**：得市值 × 70%。刻意設低，是為了讓玩家間交易比賣回銀行划算，鼓勵互動。
- **賣給玩家**：價格自訂，見[第 7 節](#7-玩家間交易)。

## 7. 玩家間交易

交易是這款遊戲最重要的社交機制。所有交易必須**雙方合意**，系統不介入定價。

### 7.1 可交易標的

一筆交易可包含任意組合：

- 現金
- 地產（含其上的建物等級一併轉移）
- 股票（依股數）
- 車輛
- **「免租券」**：承諾在接下來 N 圈內免收對方租金（系統強制執行，上限 4 圈）

免租券是為了讓交易有非資產的談判籌碼——沒有它，弱勢方常常拿不出東西換。

### 7.2 交易流程

**即時配對型**：
```
A 發起 offer → B 收到即時彈窗 → 60 秒內回應 → 成交 / 拒絕 / 逾時失效
```

**日常型**：
```
A 發起 offer → 進入 B 的待辦匣 → B 下次上線時看到
             → 48 小時 TTL → 成交 / 拒絕 / 逾時失效
```

- 一位玩家同時最多有 **5 筆**待處理 offer（防洗版）。
- offer 送出後，其中的資產被**凍結**（不可用於其他交易或抵押），直到成交或失效。
- 成交瞬間若任一方現金不足，交易自動失效。

若任一方進入清算或破產，其所有待處理 offer **立即失效並解凍資產**。凍結資產仍計入總資產，但不得在四步清算中被處分；必須先讓 offer 失效，才可被清算流程賣出、抵押或歸還無主。這避免同一塊地同時被交易與清算。

### 7.3 就地收購

當你踩到別人的地產並付完租金後，可額外發起一次針對**該格**的收購 offer。這是踩雷之後的補償性互動——「我付了你 $12,000 租金，那不如把這格賣我」。

日常型下這筆 offer 同樣走 48 小時 TTL。

### 7.4 反壟斷保護

若一筆交易會讓某位玩家達成區域壟斷，系統會在**雙方確認前**明確標示警告：「此交易將使 XXX 完成『台北市』壟斷，該區租金翻倍」。

不阻止，只揭露。避免有人因為不熟規則被坑，同時保留談判的樂趣。

免租券優先於所有租金加成。若免租期間對方完成壟斷，該次租金仍為 0；免租期結束後才套用壟斷租金。理由是免租券是雙方合意的合約，不能因之後的地產變動被單方面稀釋。

## 8. 股票系統

### 8.1 標的

**50 檔，全部沿用真實代號與名稱：**

| 類別 | 數量 | 說明 |
|---|---|---|
| 個股 | 30 | 權值股，涵蓋半導體／電子製造／金融／傳產／電信／食品零售／汽車／航運 |
| 被動式 ETF | 8 | 市值型、高股息、低波動、海外、債券 |
| **主動式 ETF** | **12** | 代號結尾 `A`，2025–2026 台灣最熱門的新品類 |

清單見 [04 §2](04-economy-and-realdata.md#2-股票標的)。

**主動式 ETF 在遊戲中的定位**：波動高於被動 ETF、低於個股，是「不想選股又想要超額報酬」的中間選項。因為掛牌時間短、淨值多在 $10–30 區間，**單價低、入手門檻低，特別適合低起點玩家**——這讓它在設計上承擔了一個具體的功能，而不只是為了跟上市場潮流。

### 8.2 價格：直接使用真實股價，一律 T+1

```
遊戲內股價 = 該檔的真實收盤價（前一交易日）
```

**不做任何映射或縮放。** 台積電在遊戲裡就是兩千多塊一股，中鋼就是十幾塊。

為什麼可以直接用真實價（前一版曾採「統一基準價 $1,000 + 套用漲跌幅」，已廢除）：

| 理由 | 說明 |
|---|---|
| **尺度本來就吻合** | 起始現金 $180,000 可買 74 股台積電、1,734 股 0050、7,722 股主動式 ETF。因為最小單位是「股」不是「張」，高價股一樣買得起 |
| **沉浸感** | 「我買了 100 股台積電」比「我買了 100 單位的虛擬台積電」真實得多 |
| **少一層抽象** | 不需要維護映射層，也不會出現「遊戲裡漲了但真實跌了」的對不上 |
| **T+1 沒有即時壓力** | 價格一天只變一次，玩家不需要盯盤，也不觸碰盤中延遲揭露的規範 |

### 8.3 何時能交易：季度事務

**股票不是棋盤格，也沒有時窗。** 交易併入通過起點的[季度事務](#18-季度事務)——就是你回到起點時順手做的一件事，一圈一次。

證交所格已從棋盤移除。前兩版分別用過「全域開盤鐘」與「過起點後 N 小時個人時窗」，都已廢除：前者要協調所有人，後者仍有時限壓力（「我上線時剛好過期」）。

**日常型下三件事天然對齊：**

```
通過起點  =  1 圈  =  1 次季度事務  =  1 次 T+1 價格更新
```

每天預期約一次交易機會，不早不晚，也不需要盯任何時鐘。

**即時配對型的季度事務是非阻塞側欄**——你可以在別人回合時慢慢處理，不卡住牌桌。

### 8.4 價格何時推進

**兩種模式規則一致：每圈推進一個真實交易日。** 休市日沿用前一交易日收盤價。

- 日常型：每日固定擲骰，通過起點才推進一個交易日；長期預期約每日一次
- 即時配對型：整局在真實世界只過了 20–45 分鐘，若不推進價格則股價紋風不動、股票淪為呆滯資產。改為每圈跨一個交易日後，一局能回放 4 天的真實走勢。開局時決定起始日期

### 8.5 交易規則

| 項目 | 數值 |
|---|---|
| 最小單位 | **1 股**（不設張，降低門檻） |
| 手續費 | **0.1425%**，最低 $20 |
| 證交稅 | **0.3%**，僅賣出時課徵 |
| 單一標的持有上限 | 總資產的 **60%** |
| 融資融券／放空 | **不開放** |

**不可放空、不可融資融券**——這是遊戲，不是模擬器。**v1 沒有任何槓桿管道**：唯一的槓桿是[股票質押](#122-貸款產品)，而它延到 v1.1。所以 v1 的股票風險只有價格波動本身，不會出現「借錢買股票然後被追繳」。

單一標的 60% 上限是為了防止 all-in 賭博式玩法毀掉遊戲節奏。

### 8.6 股息

每 **4 圈**（＝1 遊戲年）配息一次，金額為持股市值的 **3.2%**（約當台股年均殖利率）。不逐檔區分殖利率——這是刻意的簡化，避免玩家為了股息去背四十檔標的的配息政策。

## 9. 職業、進修、轉職、副業

### 9.1 職業層級

職業分三級，決定轉職的自由度：

| 層級 | 職業 |
|---|---|
| T1 | 服務業、網紅、房仲 |
| T2 | 公務員、醫療、金融業、律師、保險業務 |
| T3 | 工程師 |

職業不是單純薪水差異，而是不同起手策略：

| 職業 | 核心玩法 | 主要代價 |
|---|---|---|
| 服務業 | 其他玩家休閒消費時可接班賺小費 | 收入仰賴其他玩家踩娛樂格 |
| 網紅 | 粉絲數帶來訂閱／團購收入；機會、命運、旅遊都能變成內容素材 | 沒有固定薪資，收入仰賴粉絲成長 |
| 房仲 | 地產購買與玩家間房屋交易抽佣 | 沒有固定薪資，收入仰賴市場交易 |
| 公務員 | 發起公共標案，讓其他玩家自行評估是否參與國庫合約 | 需要有人參與；若全桌都不投標則無收入 |
| 醫療 | 經營醫療體系，收取健檢、傷病、急救、住院與提前出院費用 | 收入仰賴其他玩家經過醫院格或發生醫療事件 |
| 金融業 | 私下提供貸款，讓缺現金者避免立即違約或破產 | 不提供手續費或信貸利率優惠，且需承擔借款人倒帳風險 |
| 律師 | 其他玩家遇到交易爭議、訴訟、罰單、追債、賠償或車禍責任時可受任處理 | 收入仰賴其他玩家委任，且不能替自己收服務費 |
| 保險業務 | 玩家投保時抽取保費佣金 | 需要玩家購買保險才有價值 |
| 工程師 | 擲骰後可做路線最佳化 | 高薪職業，需透過進修或開局抽取取得 |

網紅的收入來自市場，不從其他玩家現金扣除，也不依玩家數直接調整。它由粉絲數決定：起始粉絲低，每圈自然小幅成長；遇到機會、命運或旅遊事件時，因為可以發布內容而額外增加粉絲。每圈收入仍有上限，避免後期變成無限印鈔。

職業主技能的完整效果：

| 職業 | 主技能 | 效果 |
|---|---|---|
| 服務業 | 臨時排班 | 其他玩家踩任何娛樂／休閒格時，獲得 $3,000，不扣健康 |
| 網紅 | 流量飛輪 | 依粉絲數取得每圈收入；機會、命運、旅遊會增加粉絲 |
| 房仲 | 房產佣金 | 直接買地可由買家指定房仲：成交價省 10%，但買家另付原價 6% 服務費給房仲；玩家間房屋交易強制買賣雙方各付 3%，多名房仲隨機抽一名；房仲自交易免佣 |
| 公務員 | 公共標案 | 每 2 圈開一個國庫標案；公務員不能自己接標案；其他玩家可自行評估是否以 $1,000,000 標案金額參與，得標者毛利為 60%–80%，並支付標案金額 30% 給公務員作為承辦費；資金不足或無合格參與者則放棄 |
| 醫療 | 醫療體系經營 | 玩家經過或停在醫院格、疾病、車禍、急救、提前出院、懷孕生產等醫療支出，都支付給醫療體系；多名醫療職業共同收入池並平均分潤 |
| 金融業 | 私人放貸 | 銀行貸款之外，只有金融業玩家可以私下放貸；玩家買地、付租金、罰款、稅金、最低應繳或破產前現金不足時，可向金融業借款；一般玩家之間不能互借 |
| 律師 | 法律代理 | 其他玩家遇到交易爭議、訴訟、罰單、追債、賠償或車禍責任時，可付 $80,000 委任律師；律師使有利結果機率 +40% |
| 保險業務 | 保單佣金 | 任何玩家購買保險時抽取保費 10%；多名保險業務時隨機抽一名 |
| 工程師 | 路線最佳化 | 每圈 1 次，擲骰後可調整步數 −1/0/+1；不可與車輛疊成 +2 |

公共標案的承辦費由得標玩家支付，不由國庫支付。例：標案金額 $1,000,000、毛利 60%，得標者總收入 $1,600,000；公務員收取標案金額 30%（$300,000）作為承辦費；扣除承辦費後的剩餘 70% 作為履約評分與得標權重基礎。公務員不能自己接標案；若參與者資金不足或沒有合格參與者，該次標案放棄。

**轉職與進修都在[季度事務](#18-季度事務)辦理**（進修中心格已從棋盤移除）。

### 9.2 轉職

- **同層級**內轉職：免費，立即生效，每局限 2 次。
- **跨層級向上**：必須先完成對應的**進修**。
- **向下**：隨時可以，但不會有人想。

### 9.3 進修

| 課程 | 學費 | 在學圈數 | 解鎖 |
|---|---|---|---|
| 職訓／證照班 | $60,000 | 2 | T1 → T2 |
| 在職專班 | $250,000 | 3 | T2 → T3 |
| MBA | $800,000 | 4 | T3，且月薪 +20% 永久加成 |

**在學期間**：
- 季薪減半（進修排擠工時）
- 仍正常擲骰移動、收租、交易、買賣股票
- 每次通過起點時剩餘圈數 −1

**課程完成時才判定成效**：

| 結果 | 機率 | 效果 |
|---|---:|---|
| 有效進修 | 50% | 取得課程表列的升階、轉職門檻或 MBA 薪資加成 |
| 打水飄 | 50% | 沒有升階、沒有轉職門檻、沒有技能或薪資加成；學費不退，在學圈數也已消耗 |

這代表遊戲中的「進修」不全是有效投資，也可能是包裝成課程的割韭菜產品，例如「XX 天學會 AI」之類的高承諾課程。玩家在報名前會看到成效機率，但結果到完成時才揭曉。

進修是低起點玩家的高風險翻身路徑：成功時能快速抬高收入與融資能力，失敗時則只是好幾季收入下降與學費沉沒。這個取捨是設計的核心張力。

> **改制後進修變強了。** 第一版把進修綁在「踩到進修中心格」，等於翻身路徑要看骰運；現在只要回到起點就能報名。加上日常型有 21 圈（原本 7 圈），回本時間相對局長的佔比大幅下降。**P1 模擬必須確認進修沒有變成必選項。**

薪資加成一律用**乘法疊加**，且永久加成與暫時減益沒有先後順序差異。例如 MBA +20% 且命運卡「減薪」−10% 時，實領月薪 = 基礎月薪 × 1.20 × 0.90。顯示時四捨五入到整數元，內部計算保留小數到結算階段，避免重複四捨五入造成漂移。

### 9.4 副業

每局限選一項，選定後不可更換。於季度事務選擇，收益在每次通過起點時入帳。

| 副業 | 啟動成本 | 每圈收益 | 風險 |
|---|---|---|---|
| 網拍代購 | $30,000 | $3,000 | 無 |
| 團購主 | $80,000 | $8,000 | 10% 機率該回合收益歸零（貨到不領） |
| ~~直銷~~ 🔜 v1.1 | $150,000 | $5,000 + 每位「下線」$2,000 | 每圈 8% 機率觸發「囤貨」，扣 $50,000 |
| 接案外包 | $0 | 1D6 × $2,000 | 收益全隨機 |
| 收租代管 | $200,000 | 自己所有地產租金收入的 +10% | 無 |

**直銷的下線機制**：落於機會格時有機率「拉到下線」（最多 3 位），下線是 NPC，不影響其他玩家。這個設計是刻意的諷刺——高承諾、高波動、看似有槓桿，實際期望值不特別高。

## 10. 車輛系統

買賣車輛在[季度事務](#18-季度事務)辦理（監理站格已從棋盤移除）。不設「買車格」：車輛是財務決策，不應由骰子決定你有沒有購買機會。

| 車種 | 售價 | 移動選擇 | 每圈稅費／養護 | 住宿停車費 | 折舊 |
|---|---|---|---|---|---|
| 無 | — | 1D6 | — | — | — |
| 機車 | $80,000 | 可選擇 `骰點` 或 `骰點 + 1` | $1,000 | $500 | 每 4 圈 −25% 殘值 |
| 國產車 | $600,000 | 可選擇 `骰點` 或 `骰點 + 1` | $5,000 | $2,000 | 同上 |
| 進口車 | $1,800,000 | 可選擇 `骰點` 或 `骰點 + 1` | $15,000 | $5,000 | 同上 |

車輛的價值不是「永遠走更快」，而是**多一個落點選擇**。擲出 4 時，有車者可以選擇走 4 格或 5 格；若 5 格會踩到高租金地，就可以停在 4 格。車種差異主要在持有成本、折舊與罰鍰風險，不再用 +2、+3 放大移動距離，避免日常型失衡。

持有車輛者在地產格支付住宿費或租金時，還要額外支付停車費給系統；停車費不給地主。住在自己的地產不收停車費。

開局可能自帶車，但不可能自帶保險。小康以上家境有低機率自帶機車或國產車；進口車不作為起始資產，避免富裕玩家開局取得過多移動控制權。

### 10.1 交通風險

| 觸發 | 規則 |
|---|---|
| 自然骰出 6 且持有車輛 | 觸發超速檢定；失敗則支付交通罰鍰。若本次選擇 `骰點 + 1`，罰鍰加重 |
| 落在酒吧／酒店類休閒格且持有車輛 | 必須選擇「代駕」或「自行開車」；代駕支付固定費用，自行開車觸發酒駕檢定 |
| 超速檢定失敗 | 先支付交通罰鍰；嚴重失敗可升級為擦撞事故，歸類為意外 |
| 酒駕檢定失敗 | 支付高額罰鍰，並依命運卡監禁規則入獄；另有機率升級為車禍 |
| 命運卡「車禍受傷」 | 直接觸發事故；持有車輛者承擔完整金額，無車者視為行人／大眾運輸事故，金額減半 |

酒駕不是隨機懲罰，而是玩家在休閒格做出的風險選擇。UI 必須明確標示「代駕費用」與「自行開車的可能後果」，不能把高風險選項做成預設。

### 10.2 兩種模式下車的意義

| | 即時配對型 | 日常型 |
|---|---|---|
| 回合數 | 固定（由目標時長決定） | 每日固定擲骰次數 |
| 車輛價值 | 多一個落點選擇，可能更快通過起點 | 多一個落點選擇，能避開租金或追求無主地 |
| 好處 | 更多策略性停靠 | 更能控制住宿、租金與休閒風險 |
| 壞處 | 稅費、折舊、超速／酒駕風險 | 稅費、折舊、超速／酒駕風險 |

車輛不保證比較賺。它提高控制力，但也引入固定成本與交通風險。M3 要驗證的是「多一格選擇」是否足以抵消每圈成本。

### 10.3 出售

- 於季度事務出售：得殘值 × 90%
- 破產清算時：以殘值 × 70% 計入

## 11. 保險系統

投保與解約在[季度事務](#18-季度事務)辦理。保費**每 4 圈**（＝1 遊戲年）自動扣繳一次。

| 險種 | 保費／年 | 保障 |
|---|---|---|
| 醫療險 | $12,000 | 健康檢定與住院支出，理賠 80% |
| 意外險 | $8,000 | 命運卡的意外類支出，理賠 100%，上限 $200,000 |
| 住宅火險 | $6,000 | 颱風、地震、淹水、住宅火災等天災／住宅災損，理賠 100% |
| 責任險 | $15,000 | 一般罰款、訴訟類支出，理賠 60% |

未投保時，天災事件可能直接讓一格地產**降一級**（如 L3 → L2），且不退還升級成本。這是保險存在的意義——不是為了省小錢，是為了避免資產結構被一張卡打壞。

保險不理賠兩類事件：

- **詐騙／高風險投資損失**：玩家自願投入的創業合夥、海外基金、親友投資案，若結果為詐騙，投入本金全數損失且不理賠。
- **故意違法行為**：酒駕的罰鍰與監禁不由責任險理賠；若另有醫療費，才按醫療險規則處理。

保險是[品牌置入](00-product-overview.md#72-品牌置入次要但天花板高)最自然的槽位。

## 12. 借貸與破產

### 12.1 核貸的原則

**銀行看的是你有什麼，不是你需要多少。**

不同資產結構有不同的融資管道：有薪水的人靠信用貸款、有地產的人靠抵押。這讓「我現在缺錢該怎麼辦」在每個玩家身上有不同答案。

> v1 少了「有股票的人靠質押」這條——[股票質押延到 v1.1](#122-貸款產品)。因此 v1 的**純股票玩家沒有專屬融資管道**，只能靠信用貸款或賣股。這是切割的已知副作用，M3 要觀察它是否讓股票策略在缺現金時過度脆弱。

**申請與還款在[季度事務](#18-季度事務)辦理**，唯二例外：

| 例外時機 | 可用產品 |
|---|---|
| **購地或升級時**當場選擇「以房貸支付」 | 房屋抵押貸款 |
| 清算與隊友代償後仍不足，詢問是否借錢避免破產 | 金融業私人放貸 |

購地貸款不含[認購溢價](#-溢價是純沉沒成本)——銀行只認基價，想加價搶地就得掏現金。

### 12.2 貸款產品

| 產品 | 核貸依據 | 額度 | 利率／圈 |
|---|---|---|---|
| **信用貸款** | 薪資或可驗證變動收入 | `月薪 × 倍數`（T1 = 16、T2 = 20、T3 = 22） | 2.0% |
| **房屋抵押貸款** | 地產 | 未抵押地產市值 × 60% | 1.2% |
| **金融業私人放貸** | 金融業玩家同意 | 缺口金額與放貸方可用現金孰低 | 3.0% |
| ~~**股票質押**~~ 🔜 v1.1 | 持股 | 持股市值 × 50% | 1.5% |
| **就學貸款** | — | 固定 $300,000（僅負債家庭起手持有） | 0.5% |

**信用貸款的 22 倍上限**錨定台灣金管會對銀行無擔保債務的「月薪 22 倍」規範。職業層級越高倍數越高——這是真實的，也讓[進修轉職](#9-職業、進修、轉職、副業)多了一個薪水以外的回報：**你的融資能力也跟著升級。**

**房貸 vs 抵押的差異**（容易混淆）：

| | 抵押（見 [§6.5](#65-抵押與贖回)） | 房屋抵押貸款 |
|---|---|---|
| 取得 | 基價 × 50% | 市值 × 60% |
| 地產還能收租嗎 | ❌ | ✅ |
| 地產可出售嗎 | ✅（贖回後） | ❌（被設定為擔保品） |
| 成本 | 贖回時 +10% | 每圈 1.2% 利息 |

**股票質押的追繳機制**：若持股市值跌到貸款餘額的 **1.3 倍**以下，觸發追繳——需補現金或被強制賣出持股。這是遊戲裡唯一的槓桿風險，因為它是股票玩法最真實的一課。

> 🔜 **v1.1 — 股票質押不進 v1**（issue #7）
>
> 五種貸款裡唯一有追繳機制的產品。追繳需要**每回合監控持股市值 vs 貸款餘額**，並在觸發時執行強制賣出——那是一條全新的機制路徑；其餘四種共用同一條借款 → 計息 → 還款流程。
>
> 代價是 v1 沒有任何槓桿管道（見 [§8.5](#85-交易規則)），股票的風險教學只剩價格波動本身。這是刻意的取捨：追繳的教學價值高，但它同時是 14 條邊界情況裡 #14（追繳時玩家正在服刑）的來源。
>
> 規格原封保留於上。`config/loans.json` 中 `products[stock_pledge].enabled = false`，且已從 `origination_points.quarterly_affairs.products` 移出；v1.1 啟用時兩處都要改回。
>
> ⚠️ `docs/05-data-model.md` 的 `loan_kind` ENUM **刻意保留 `stock_pledge`**——切割在 config 層而非 schema 層，Postgres 的 enum 事後增值很麻煩。

**金融業私人放貸**是銀行之外唯一的玩家間資金管道。一般玩家之間不能互相借貸；借款人只能向金融業職業玩家提出申請。金融業玩家可以拒絕、只借部分金額、議價還款圈數，或要求擔保品。即時配對型給 60 秒回應；日常型可等到當日 23:59。若沒有金融業願意借，或借款金額不足，玩家直接破產。

若金融業私人放貸有擔保品，借款人違約或破產時，放貸方可支付 $80,000 律師處理費啟動法律程序，取回契約約定的擔保品（地產、車輛或股票）。只能取回已約定的擔保品，不能藉機拿走借款人其他資產。

職業貸款修正由 `config/loans.json` 的 `occupation_credit_modifiers` 控制，分成兩個欄位：`salary_multiple_bonus` 與 `rate_discount`。目前公務員、醫療職業信貸利率 −0.5%／圈；公務員信貸倍數另 +4（真實世界銀行確實偏好公務員）。金融業沒有手續費或信貸利率減免。

網紅與房仲沒有固定薪資，信用貸款改用最近 4 圈變動收入均值折算月收入；沒有收入紀錄時，信貸額度為 0。

### 12.3 還款與違約

- **每圈自動扣繳最低應繳** = `餘額 × 5% + 累計利息`
- 隨時可提前還款，無違約金
- **總負債上限** = 總資產 × 1.5（銀行貸款）；金融業私人放貸由放貸方自行承擔風險

現金不足以支付最低應繳 → **違約**：

| 違約次數 | 後果 |
|---|---|
| 每次 | 利率 +1.0%／圈，2 圈內不得申請新的信用貸款 |
| 累計 2 次 | 可能進入追債／支付命令類法律流程，可委任律師 |
| 累計 3 次 | **信用黑名單**——銀行信用貸款不可用；若需非銀行資金，只能向金融業玩家申請私人放貸 |

違約不會立即破產，但會讓後續融資成本螺旋上升。這是真實的債務陷阱，也是遊戲想傳達的東西之一。

信用黑名單玩家仍可向金融業玩家提出私人放貸申請，但金融業玩家沒有義務承接。黑名單的意思是失去銀行信用，不是系統保證你能取得高利資金；這讓金融業的判斷與談判成為破產邊緣的關鍵互動。

### 12.4 現金為負時的處理順序

當任一階段結束後現金為負，玩家進入**清算流程**，依序自動執行直到現金 ≥ 0：

1. 賣出股票（由持有市值最小的標的開始）
2. 抵押地產（由基價最低的開始）
3. 出售車輛
4. 賣出地產給銀行（市值 × 70%，由基價最低的開始）

### 12.5 強制清算

若上述四步全部執行完畢後現金仍為負：

**若你有家庭／伴侶** → 先進入[隊友代償](#174-共同負擔盈虧代償機制)。代償成功則不破產。

代償失敗，或你本來就沒有隊友 → 詢問場上金融業玩家是否願意私人放貸。若沒有金融業願意承接，或放貸金額仍不足 → **宣告破產**。

破產玩家：
- 立即退出本局，不再參與回合
- 名下所有資產歸還「無主」狀態（不歸給債權人）
- 計入結束條件的破產人數
- 公教職業保留 $200,000「退休金」（不計入本局，僅為結算排名用）

清算所得按順序償還：

1. 政府稅金與罰款
2. 有擔保金融業私人放貸債權
3. 無擔保金融業私人放貸債權
4. 銀行與系統債權

不足額的部分在玩家退場時沖銷。金融業私人放貸優先於銀行；有擔保者又優先於無擔保者。**資產歸還無主而非直接歸債權人**，是為了避免「打死一個人就吃掉他全部家產」的滾雪球；但約定擔保品可透過法律程序取回，避免放貸者完全沒有保障。

### 12.6 主動退出

日常型下允許主動退出（現實中人會離職、會出國）。主動退出**視同破產**處理，但不計入結束條件的破產人數——避免有人為了結束遊戲而故意退出。

主動退出的資產**立即**依破產規則釋出為無主，不等到局末。退出者不再收租、不再持有壟斷，也不保留待處理 offer；所有關係邀請與交易 offer 同步失效。這讓剩餘玩家能重新競爭土地，不會被離線玩家鎖住局面。

## 13. Standing Orders（預設指令）

### 13.1 設計理由

日常型下你可能整天沒上線。系統必須替你用完當日擲骰額度，否則局會停擺。

但「逾時就 AI 代打」不行——被系統亂打的玩家會有強烈的失控感，那是流失的直接原因。

**Standing Orders 的解法是：託管執行的是玩家自己事先設定的策略。** 你被託管了，但打出來的是你的意志。

### 13.2 可設定的規則

玩家可**隨時**設定，免費版最多 3 條，付費版 8 條。

| 類別 | 可設定項 |
|---|---|
| **出價** | 「基價 < X 才出價」／「只出基價，絕不加價」／「加價上限 +N%」／「只買 [指定縣市]」／「一律不出價」 |
| 升級 | 「現金 > X 時自動升級最高租金的地產」／「一律不升級」 |
| 交易 | 「自動拒絕所有 offer」／「自動接受淨值為正且 > X 的 offer」／「一律保留待我決定」 |
| 股票 | 「季度事務自動不動作」／「單一標的跌破成本 X% 自動賣出」 |
| 保險 | 「保費到期自動續約」／「現金 < X 時自動解約」 |
| 現金底線 | 「保留至少 $X 不動用」（優先於所有其他規則） |

**加價規則是新機制的重點。** 認購制下「要不要加價、加多少」是每天最重要的決策，託管必須能表達你的態度——保守的人設「只出基價」，積極的人設「加價上限 +20%」。

### 13.3 執行優先序

```
① 檢查現金底線 → ② 強制項（付租金、扣款，無法規避）
→ ③ 依 Standing Orders 決定出價／升級
→ ④ 未被規則覆蓋的決策一律「不動作」
```

**未設定 = 不動作**，而非「系統幫你判斷」。保守是安全的預設。

### 13.4 使用者體驗

- 首次開局時強制引導設定至少 1 條（出價規則）
- 每次被託管後，推播附上「這是系統依你的設定做的決定」＋ 一鍵調整入口
- 局內隨時可見「若我今天沒上線，會發生什麼」的預覽

## 14. 回合推進

### 14.1 即時配對型：即時輪流

- 每回合 **20 秒**倒數
- 倒數歸零 → 執行 Standing Orders → 推進
- 連續 3 次逾時 → 標記為「掛機」，後續回合倒數縮短為 8 秒

### 14.2 日常型：非同步 + 每日結算

**沒有回合時窗，沒有排隊。**

```
當日任意時間 → 你用完今日擲骰額度 → 完成
                    ⋮
              （其他人也各自在任意時間行動，互不阻塞）
                    ⋮
每日 00:00 → 結算 → 群組推播「昨日戰況」
```

| 為什麼可以並行 | 說明 |
|---|---|
| 移動 | 各走各的，互不影響 |
| 付租金 | A 付給 C 跟 B 付給 C 誰先誰後，結果一樣 |
| 抽卡、領薪、扣款 | 只影響自己 |
| 升級自己的地 | 不與任何人衝突 |
| **買無主地** | ⚠️ **唯一的衝突點** → 由[出價認購](#63-出價認購日常型)處理 |

**這是整個設計的核心洞察：不必為了一件不能並行的事，把所有事都排成隊。**

### 14.3 每日 00:00 結算

```
① 仲裁所有認購（最高價得標，同價則當日順位在前者勝）
② 落選者全額退款
③ 當日未行動者 → 執行 Standing Orders 自動用完今日擲骰額度
④ 順位輪替一位
⑤ 檢查結束條件
⑥ 生成「昨日戰況」推播到 LINE 群組
```

**⑥ 是這個機制的意外收穫。** 每天早上群組收到一則昨日戰報（誰買到什麼、誰付了誰多少租金、誰破產了），這是比「輪到你了」更強的社交鉤子——它給了群組**共同的話題**，而不只是個人的提醒。

### 14.4 可預測性從哪來

第一版靠「你的回合大概每天 19:30」建立習慣。非同步後這個錨點消失了，改由三件事取代：

| 錨點 | 內容 |
|---|---|
| **每日戰報** | 固定 00:00 結算、早上推播，形成日曆節奏 |
| **今日進度** | 「今天 12 / 30 人已行動，你還沒動」 |
| **認購倒數** | 「你對鹿港鎮的出價將於 4 小時 20 分後結算」 |

玩家不再需要在特定時刻上線，只需要**每天找個時間玩一次**——這正是日常型該有的樣子。

## 15. 結束條件與勝負判定

### 15.1 觸發條件（任一滿足即結束）

| 條件 | 即時配對型 | 日常型 |
|---|---|---|
| 任一玩家總資產達標 | **動態門檻**（≈ $2.1M–$5.2M，依圈數） | **動態門檻**（≈ $8.2M） |
| 破產比例 | ≥ 20% 玩家破產（>20 人桌為 30%） | 同左 |
| 局長上限 | **2–12 圈**（由目標時長決定） | **21 天**（圈數由實際通過起點次數決定） |
| 時間上限 | 目標時長 × 1.5 | 21 天 |

**資產門檻是動態的，不是固定值。** 圈數在新架構下是可變的（即時配對型 2–12 圈、日常型以每日擲骰額度估算預期圈數），經濟規模差 5 倍以上，單一常數無法同時服務兩者。

```
預估薪資注入 = 圈數上限 × 全桌平均季薪

資產門檻 = max( (開局全桌平均總資產 + 預估薪資注入) × 2.5 ,
                開局全桌最高總資產 × 1.6 )
```

**第一項自動隨局長縮放**，不需要人工調參——這取代了第一版的 M 值制。

**第二項是必要的下界**：一位「富裕家庭 + 工程師」起始總資產可能接近短局第一項門檻，沒有這條，短局可能在第 1 回合就結束。因此也必須**在開局後立即檢查一次結束條件**。

門檻於開局時計算一次並固定，局內全程可見。房主可在 ±50% 範圍內調整。完整推導見 [02 §4.3](02-game-balance.md#43-資產結束門檻)。

破產比例以**開局人數**為分母，無條件進位。2–4 人桌時 1 人破產即觸發（`ceil(4 × 0.2) = 1`）；超過 20 人的桌門檻放寬至 30%。

局長上限亦可由房主在 ±50% 範圍內調整。

同一批次內多人破產時，先把該批次所有清算、代償與破產事件全部結算完，再檢查結束條件。破產人數全部計入；若因此達到破產比例，遊戲在該批次結束後結束。排名時，破產者依破產前最後一次總資產由高到低排序；仍相同則依破產事件發生時間，較晚破產者排名較前。

同一批次內多人同時達到資產門檻時，不用「誰先觸發」決勝，而是先完成該批次全部事件，再以總資產排名。這符合非同步日常型的直覺：每日 00:00 仲裁是一個批次，不該讓伺服器處理順序決定勝負。

### 15.2 勝負判定

結束時依**總資產**排名：

```
總資產 = 現金
       + Σ 地產市值（抵押中的以淨值計）
       + Σ 股票市值（以最後一次更新價計）
       + 車輛殘值
       − 貸款餘額（含累計利息）
```

排名 tie-breaker 固定為：總資產較高者勝；若相同，現金較高者勝；若仍相同，持有未抵押地產市值較高者勝；若仍相同，依開局順位在前者勝。這套規則同時用於局末排名與同批次達標時的名次判定。

### 15.3 結算與戰報

結算階段：
1. 凍結所有動作
2. 公開 `server_seed`（供驗算骰子）
3. 計算最終排名
4. 由 `game_events` 事件流生成**戰報**

戰報包含（自動選取最戲劇性的片段）：
- 最終排名與資產曲線圖
- 「本局最大一筆租金」
- 「最早破產的人」與「撐最久的人」
- 「地產大亨」（持有最多格）
- 「股神／韭菜」（股票總損益極值）
- 「最活躍交易者」
- 每個人的個人化一句話總結

戰報是一張 Flex Message 圖卡，可一鍵分享到其他 LINE 群組——這是產品的主要擴散點（見 [00](00-product-overview.md#病毒擴散機制)）。

## 16. 兩種模式的參數差異

**兩種模式共用同一套規則引擎與同一份數值表**，差異只在下表列出的參數。這是刻意的架構決策——維護兩套規則會讓平衡工作量翻倍。

| 參數 | 即時配對型 | 日常型 |
|---|---|---|
| 人數 | 2–8 | 2–30 |
| **回合單位** | **擲骰 1 次** | **固定擲骰次數的一日行動** |
| 推進方式 | 即時嚴格輪流 | **非同步**，當日任意時間 |
| 回合時限 | 20 秒 | 一整天（00:00 結算） |
| 棋盤 | 16–32 格（依目標時長與人數自動配置） | 28 / 36 / 48 格（依人數） |
| 局長 | 2–12 圈 或 目標時長 × 1.5 | 21 天；預期約 21 圈，實際依骰點浮動 |
| **購地方式** | 立即成交 | **出價認購**，每日仲裁 |
| 順位的作用 | 真正的輪流順序 | 同價競標的仲裁權，**每日輪替** |
| 監禁／住院上限 | 1 回合 | 3 回合 |
| 交易 offer TTL | 60 秒 | 48 小時 |
| Realtime 連線 | 常駐 WebSocket | 不常駐（推播 + 拉取） |

**兩者共用同一套規則引擎與同一份數值表。** 季度事務、股票、貸款、保險、家庭系統、結束門檻公式全部一致——差異只在上表。

### 16.1 兩種模式的策略差異是刻意的

圈數差距極大（即時配對型 2–12 圈 vs 日常型預期約 21 圈），最優策略天然分岔：

| | 即時配對型 | 日常型 |
|---|---|---|
| 進修 | 短局來不及回本 | 明顯值得（21 圈） |
| 起手優勢 | **決定性**——低起點幾乎追不上 | 可被翻盤 |
| 搶地 | 立即成交，先手優勢明顯 | 出價競標，錢比順序重要 |
| 主要致富手段 | 搶地 + 壟斷 | 進修轉職 + 長期地產經營 |
| 適合誰 | 想一次爽完 | 想每天玩三分鐘 |

低起點玩家在即時配對型明顯劣勢，這點必須在模式選擇的 UI 上誠實說明——**日常型才是翻身者的主場**。

### 16.2 即時配對型的目標時長自動配置

房主只選「想玩多久」（20 / 30 / 45 分），系統依人數反推格數與圈數。

**因為時長 = 回合數 × 人數，固定 preset 給不了固定時長**——同一組設定 4 人 18 分、8 人 34 分。讓玩家自訂他真正在乎的東西（時間），而不是他無法推理的東西（格數／圈數）。

大廳即時顯示預覽：`6 人 · 22 格 · 4 圈 · 約 30 分鐘`，人數變動即時重算。

完整公式與各組合輸出見 [02 §4.2](02-game-balance.md#42-即時配對型目標時長自動配置)。

## 17. 家庭系統（情侶／結婚／家庭）

玩家可在局進行中與其他玩家組成關係，**共同負擔盈虧**。上限 8 人。

### 17.1 核心設計：組隊改變的是「風險」，不是「勝利條件」

如果組隊能直接提升勝率，8 人抱團就會變成唯一解，遊戲就毀了。

所以設計是：

| 你得到 | 你付出 |
|---|---|
| 隊內互不收租（或減半） | 每圈繳「家用」 |
| **破產前隊友強制代償** | 稅率加成（隊伍越大越高） |
| 租金收入按持份分潤 | 分潤稀釋你的個人資產 |
| | 隊友代償失敗時全隊「家道中落」 |

**勝負仍以個人總資產排名**（額外顯示家庭排名），結束條件的資產門檻也看個人、不看家庭總和。組隊不能靠人多直接衝線。

這也符合主題：**家庭讓你更安全，但也更難暴富。**

### 17.2 三種關係層級

| 關係 | 人數 | 成立成本 | 隊內租金 | 家用／圈 | 分潤 | 稅率加成 | 代償義務 |
|---|---|---|---|---|---|---|---|
| **情侶** | 2 | 免費 | ×0.5 | 季薪 5% | 10% | — | 30% |
| **已婚** | 2 | 見下 | **免收** | 季薪 10% | 25% | +10% | 100% |
| **家庭** | 3–4 | 每人 $100,000 | 免收 | 季薪 15% | 30% | +20% | 100% |
| **大家庭** | 5–8 | 每人 $100,000 | 免收 | 季薪 20% | 35% | +40% | 100% |

家庭與大家庭**必須以一對已婚成員為核心**才能成立。

**情侶是免費且可隨時分手的輕量入口**，讓玩家先體驗機制再決定要不要投入。

### 17.3 結婚與離婚

**結婚**二選一：

| 方式 | 費用 | 附帶 |
|---|---|---|
| 辦婚禮 | $300,000 | 收到親友禮金 = `全桌人數 × $12,000` |
| 公證結婚 | $50,000 | 無 |

25 人以上的局辦婚禮才回本（$300,000 vs 25 × $12,000 = $300,000）。**人多的局辦婚禮才划算——這個取捨本身就很真實。**

**離婚**：律師費 $150,000 ＋ 雙方總資產**對分**。代價高到讓「要不要結婚」是個真決策，而不是隨手點的按鈕。

整局最多變更關係 **2 次**（含分手、離婚、加入或退出家庭），防止玩家依局勢反覆重組。

### 17.4 共同負擔盈虧：代償機制

**這是整個系統存在的意義。**

當某位成員完成[四步清算](#124-現金為負時的處理順序)後現金仍為負：

```
① 家庭基金代付
      ↓ 不足
② 隊友按持份強制扣款（單次上限為其現金的 50%）
      ↓ 仍不足
③ 該成員破產 + 全隊「家道中落」：所有成員損失 10% 現金
```

**單次代償上限 50%** 是為了避免一人拖垮全家。**家道中落**則確保組隊不是無風險的——你救不起隊友，全家一起受傷。

家庭成員破產後，該成員立即退出家庭；其持份先用於抵銷家庭基金中的未分配權益，不足或剩餘都不再向隊友追討。家庭若失去「一對已婚成員」的核心，降級為可成立的最高關係層級；若剩餘成員不足 2 人，家庭解散並立刻按持份分配基金。隊友代償失敗觸發的「家道中落」在降級或解散前先結算，避免靠解散逃避共同風險。

服刑中的玩家可以被家庭代償。代償是破產流程的一部分，不是服刑者主動做財務操作；因此不受「服刑期間不能買賣股票、申請貸款、進修」限制。若代償成功，服刑狀態照常延續；若失敗，仍宣告破產。

### 17.5 家庭基金

- 每圈收入結算時，每位成員繳交季薪的家用比例進基金
- 成員的租金收入按分潤比例進基金
- **每 4 圈與局末**按持份分配，持份 = 你累計繳交額佔基金總繳交額的比例

賺得多的人繳得多、分得也多，但實質上是把個人收益攤平給全隊——這是「共同負擔盈虧」的正向那一半。

### 17.6 反濫用限制

| 限制 | 理由 |
|---|---|
| **隊內不可轉移地產**（現金、股票可以） | 否則 8 人可把地產集中到一人身上刷[區域壟斷](#64-區域壟斷)，破壞壟斷機制的難度設計 |
| 上限 8 人 | 8 人可能持有半數地產，隊內免租的覆蓋面再大就會對外部玩家形成無解的租金牆 |
| 稅率加成隨規模遞增 | 主要平衡閥 |
| 家用比例隨規模遞增 | 次要平衡閥 |

**平衡監控**：P1 蒙地卡羅必須驗證組隊者與單身者的勝率差距 < 8 個百分點。若組隊明顯較強，優先調高稅率加成與家用比例，**而非削弱代償**——代償是這個系統存在的理由。

### 17.7 邀請流程

```
A 發出關係邀請 → B 收到 → 同意 / 拒絕 / 逾時失效
```

TTL：日常型 48 小時、即時配對型 60 秒。與[交易 offer](#72-交易流程) 共用同一套待辦匣。

機會卡 **O22「聯誼認識新朋友」** 可讓你立即向任一玩家發出情侶邀請且免除成立成本——這是組隊系統的引導入口，讓沒注意到這個功能的玩家有機會被推一把。

## 18. 季度事務

**通過起點 = 這一季的財務結算日。** 所有理財動作集中於此。

```
┌────────────────────────────────┐
│ 通過起點 · 第 3 季（第 3 天）    │
├────────────────────────────────┤
│ ✓ 季薪              +$174,000  │
│ ✓ 租金收入           +$88,200  │
│ ✓ 副業（網拍代購）    +$3,000  │
│ − 貸款最低應繳       −$42,500  │
│ − 車輛養護           −$5,000   │
│ − 家用（已婚 10%）   −$17,400  │
├────────────────────────────────┤
│ 本季可辦理（各限一次）：         │
│   ▸ 股票交易     2330 ▲2.3%   │
│   ▸ 貸款申請 / 還款             │
│   ▸ 進修 / 轉職                 │
│   ▸ 買車 / 賣車                 │
│   ▸ 保險投保 / 解約             │
│   ▸ 副業選擇（每局限一次）       │
├────────────────────────────────┤
│      [ 完成，繼續下一季 ]       │
└────────────────────────────────┘
```

### 18.1 為什麼把理財全部集中在這裡

第一版把股票、車輛、進修各自綁在證交所格、監理站格、進修中心格上。那有三個問題：

| 問題 | 說明 |
|---|---|
| **翻身路徑被骰運封死** | 整局沒踩到進修中心，低起點玩家就沒有翻身管道 |
| **UI 囉嗦** | 這些動作散在自由行動階段，每回合都要問玩家一次 |
| **棋盤格位被佔用** | 3 格功能格 = 3 個台灣鄉鎮上不了場 |

集中之後：

- **棋盤只講一件事**：移動與地產
- **理財有固定節奏**：一季一次，符合現實隱喻（每季檢視一次財務）
- **地產格變多**，全台涵蓋度提升
- **進修不再靠運氣**

### 18.2 這也決定了日常型的節奏

既然過起點是唯一的理財時機，**過起點的頻率就是遊戲的心跳**。

日常型改為固定擲骰次數後，「一天」不再保證等於「一季」。每位玩家每天面對相同擲骰額度；通過起點才進入下一季、觸發健康檢定與季度事務。長期平均仍接近每日一圈，但不讓「高點數玩家用較少事件完成一圈」變成結構性優勢。

### 18.3 兩種模式的呈現差異

| | 即時配對型 | 日常型 |
|---|---|---|
| 何時開啟 | 通過起點時 | 通過起點時（＝今日行動終點） |
| 是否阻塞他人 | **否**，非阻塞側欄 | 不適用（非同步） |
| 處理時間 | 可在別人回合時慢慢處理 | 沒有時限 |

**即時配對型的非阻塞設計很重要。** 若季度事務會卡住牌桌，一個猶豫的玩家就能讓其他 5 人等 60 秒。改為側欄後，它反而利用了「看別人回合」的空檔。

### 18.4 服刑與住院期間沒有季度事務

被關或住院時走不到起點，所以整段期間**領不到季薪、不能買賣股票、不能借錢周轉**。

這是[監獄與醫院](#58-監獄與醫院的對照)真正痛的地方——比薪水減半更實質。你的財務被完全凍結。

## 19. 健康、住宿、休閒與生育

本節整理 M1 新增的生活規則。原則是：地產仍是主軸；健康、住宿、休閒、車輛與家庭事件提供現實感與現金流壓力，但不能壓過買地、收租、交易。

### 19.1 棋盤與每日節奏

| 模式 | 棋盤尺寸 | 每日／每回合擲骰 | 預期通過起點頻率 |
|---|---:|---:|---|
| 即時配對型 | 16–32 格 | 每回合 1 次 | 依局長與移動選擇浮動 |
| 日常型小桌 | 28 格 | 每日 8 次 | 長期約每日 1 圈 |
| 日常型中桌 | 36 格 | 每日 10 次 | 長期約每日 1 圈 |
| 日常型大桌 | 48 格 | 每日 14 次 | 長期約每日 1 圈 |

日常型所有玩家每天拿到同樣擲骰額度，不排隊。某玩家今天是否通過起點，由骰點、車輛選擇與落點效果共同決定；通過起點就立刻做一圈結算，未通過則把位置留到隔天。

### 19.2 格子種類

| 類型 | 是否為格子 | 主要作用 |
|---|---|---|
| 起點 | 是 | 通過或停留時觸發健康檢定、季薪、貸款、股票、保險、車輛等季度事務 |
| 地產 | 是 | 購買／認購、住宿、收租、升級、交易 |
| 機會 | 是 | 獎金、補助、折扣、消費券、關係事件；不放投資消息 |
| 命運 | 是 | 裁員、減薪、罰款、稅務、天災、監禁、市場衝擊；不放一般疾病 |
| 休閒 | 是 | 電影、餐廳、溫泉、酒吧／酒店等消費與關係互動 |
| 稅捐處 | 是 | 依總資產累進課稅，稅金進國庫池 |
| 監獄 | 是 | 走到無害；只有命運事件會使玩家入獄 |
| 醫院 | 是 | 經過或走到是健檢，費用支付給醫療體系；疾病或事故才會住院 |
| 健康事件 | 否 | 每次通過起點時檢定一次 |

### 19.3 健康、運氣與疾病

健康事件**每圈檢定一次**，不放進命運格。每位玩家有 `health_score`（0–100）與 `luck_score`（低／普通／高或等價數值），觸發點是通過或停留起點時，順序為：

1. 健康檢定
2. 醫療險理賠或自付
3. 若需住院，套用住院狀態
4. 執行季度事務的其他收入與扣款

健康分數的規則：

- 健康越低，疾病觸發率與住院率越高。
- 健康低於門檻時，慢性病與住院類事件權重提高。
- 健康可透過醫院健檢、休閒、溫泉、旅遊、部分機會事件提高。
- 健康會因疾病、住院、過勞停工、部分命運事件降低。
- 不設壓力分數；壓力、過勞、休息全部折算到健康。

運氣分數的規則：

- 運氣不影響骰點、股票價格、認購勝負或 server_seed。
- 運氣只微幅調整機會／命運抽卡權重，例如高運氣較容易抽到補助，低運氣較容易抽到小額支出。
- 運氣可被少數事件短期提高或降低，但不應成為主要策略軸。
- UI 只顯示粗略狀態，例如「低潮／普通／順風」，避免玩家誤以為系統暗改骰子。

疾病清單以台灣官方統計作為主題來源，但不直接把死亡率當成遊戲機率。v1 初始疾病池：

| 類別 | 性別條件 | 遊戲效果方向 |
|---|---|---|
| 癌症：肺癌、肝癌、結直腸癌 | 不限 | 高額醫療費，低機率住院 |
| 癌症：女性乳癌、卵巢癌 | 女性角色 | 中高額醫療費，可能需住院 |
| 癌症：攝護腺癌 | 男性角色 | 中高額醫療費，可能需住院 |
| 心臟疾病／腦血管疾病 | 不限 | 高額醫療費，較高住院機率 |
| 肺炎／慢性下呼吸道疾病 | 不限 | 中額醫療費，住院 1–2 回合 |
| 糖尿病／高血壓性疾病／腎病 | 不限 | 持續數圈的小額扣款或醫療管理費 |

M3 調整的是「每圈觸發率、各疾病權重、費用、住院率」。M1 只定機制與資料來源。

### 19.4 住宿與地產落點

每次落在地產格，都要解決當晚住宿：

- 無主地：可購買／認購，或只住宿。
- 購買／認購：支付地價或凍結出價，另支付交易住宿成本給系統。
- 不買：支付住宿費給系統。
- 別人的地：支付住宿費／租金給地主。
- 自己的地：免費住宿，可選擇升級。
- 當日待認購未結算的地：仍視為無主，住宿費付給系統。

住宿費是地產格的最低現金壓力，避免玩家一路放棄購地卻沒有成本。住宿費倍率、買地時的交易住宿成本、壟斷加成是否影響住宿費，全部留給 config 校正。

### 19.5 休閒與關係互動

休閒格是現金 sink，也讓情侶／家庭有可見互動。

| 休閒類型 | 成本 | 可能附加 |
|---|---|---|
| 電影 | 低 | 情侶同行可降低一次關係事件負面機率 |
| 餐廳 | 低至中 | 情侶／家庭可共同分攤 |
| 溫泉 | 中 | 提高健康；下次健康檢定風險小幅下降 |
| 旅遊 | 高 | 大幅提高健康，可能提高短期運氣，並觸發旅伴關係事件 |
| 酒吧／酒店 | 中至高 | 持有車輛者必須選代駕或酒駕檢定 |

若玩家有情侶、配偶或家庭成員，踩到休閒格時可選擇：

1. 只有落點者參加：只扣落點者現金。
2. 邀請關係成員參加：對方不消耗擲骰額度，費用依關係設定分攤。
3. 家庭共同活動：可由家庭基金支付，但受基金餘額限制。

旅遊是休閒格的高成本子類型，不是獨立格。踩到旅遊時，系統先隨機產生目的地與可同行人數，再讓玩家決定是否參加：

| 旅遊結果 | 好處 |
|---|---|
| 國內小旅行 | 健康小幅提高，可能獲得一回合住宿費折扣 |
| 溫泉／療癒旅行 | 健康中幅提高，下次健康檢定風險降低 |
| 家庭旅遊 | 參與成員健康提高，家庭關係事件正面權重提高 |
| 高級度假 | 健康大幅提高，短期運氣提高，但花費高 |
| 出差順遊 | 費用較低，可能觸發職業／副業小額收益 |

旅遊的核心取捨是「用高額現金換健康與關係穩定」。不能讓旅遊直接給大筆現金，否則它會從生活事件變成投資選項。

### 19.6 懷孕、生產、認養與小孩

小孩可由懷孕生產或認養取得。這不是組隊專屬系統；單身玩家也可以認養，但必須符合財富門檻。

取得小孩的基本條件：

- 至少持有 1 格未抵押地產，代表有穩定住所。
- 現金不得為負，且不得處於破產清算流程。
- 每位玩家或財富共享隊伍 v1 最多管理 1 個孩子棋子。
- 認養需支付一次性安置費；懷孕生產需經過待產期與醫療支出。

懷孕是機會／命運的關係事件，只會在具關係狀態的玩家中觸發。它不放在健康檢定裡，因為它是家庭決策，不是疾病。觸發後，玩家可選：

| 選項 | 立即效果 | 後續效果 |
|---|---|---|
| 終止妊娠 | 支付醫療費；事件結束 | 無小孩狀態 |
| 生產 | 進入待產狀態，若干圈後出生 | 出生時獲得育嬰補助，之後每圈支付育兒成本 |
| 認養 | 支付安置費並通過財富門檻檢查 | 立即取得孩子棋子，之後每圈支付育兒成本 |

小孩不是一般玩家，但會新增一個**子玩家棋子**。效果：

- 每個小孩每圈都有固定育兒成本。
- 出生時可獲得一次性育嬰補助，或每圈小額補助。
- 有小孩的玩家或隊伍，每日可額外操作孩子棋子的一段獨立行動。孩子棋子有自己的位置、骰子與落點事件。
- 日常型下，孩子棋子的目標是獨立走完一圈；為避免操作量失控，最多使用該桌成人每日擲骰額度（28/36/48 格為 8/10/14 次）。若未通過起點，位置留到隔天。
- 即時配對型下，孩子棋子不插入正式回合序；每位隊伍成員完成自己的回合後，隊伍可選擇是否讓孩子棋子擲 1 次。
- 單身玩家的孩子棋子由該玩家管理；情侶、已婚或家庭的孩子棋子由隊伍共同管理。
- 孩子棋子的資產、支出與收益歸屬其監護者；若監護者是隊伍，則歸屬家庭共同管理。
- 孩子棋子可以住宿、觸發休閒或小額事件，但不能購買地產、股票、貸款、結婚、開車或成為交易對象。
- 孩子棋子通過起點不領成人季薪，也不觸發成人季度事務；可觸發育嬰補助、教育補助或健康相關事件。
- v1 每位玩家或每個財富共享隊伍最多 1 個孩子棋子；是否允許多個小孩留到 M3/M6 驗證後再開。

M3 必須驗證：孩子棋子的額外落點是否讓組隊策略過強。若過強，優先調高每圈育兒成本、限制孩子可觸發的格子類型，或降低育嬰補助，而不是移除孩子棋子。

### 19.7 機會與命運的範圍

機會卡的 v1 範圍：

- 獎金
- 政府補助
- 消費券
- 學費補助
- 保費折扣
- 關係事件
- 小額移動事件
- 可拒絕的高風險邀約（創業合夥、海外基金、親友投資案）

高風險邀約的規則：

- UI 必須給「拒絕」選項，拒絕不扣錢。
- 投入金額由 `NW` 與 `available_loan_capacity` 計算，避免固定金額對富人太小、對窮人太致命。
- 結果延後揭曉；v1 預設 30% 是真投資、70% 是詐騙。
- 真投資在 2 圈後取得約定報酬；詐騙則投入本金全數損失。
- 詐騙本金損失不受保險理賠。
- 不得透露股票、房市或特定標的方向，避免變成投資明牌。

機會卡不放：

- 投資消息
- 內線消息
- 明示股票方向
- 讓玩家繞過股票風險的提示

命運卡的 v1 範圍：

- 裁員、減薪、失業給付
- 交通罰鍰與酒駕後果
- 交易爭議與訴訟
- 天災、住宅火災與地產損害
- 車禍與一般事故
- 稅務稽查
- 監禁
- 市場衝擊
- 懷孕等家庭突發事件

命運卡不放一般疾病；疾病統一由每圈健康檢定處理。

## 20. M1 邊界情況定案

本節是 issue #8 的索引。規則寫回上方對應章節；這裡只列決策與位置，供 M2 實作時對照。

| # | 情況 | v1 決策 |
|---|---|---|
| 1 | 認購得標前破產 | 仲裁前破產則取消該玩家認購並解凍現金；得標後才破產則先成交再清算。見 [§6.3](#63-出價認購日常型) |
| 2 | 同一天多人破產 | 同批次全部結算完再檢查結束條件；全部計入破產人數。見 [§15.1](#151-結束條件) |
| 3 | 多人同時達資產門檻 | 批次結束後按總資產排名，不看伺服器處理順序。見 [§15.1](#151-結束條件) |
| 4 | 認購凍結現金是否算總資產 | 算。凍結現金仍是現金，只是不能重複動用。見 [§1](#1-名詞定義) |
| 5 | 家庭成員破產 | 先代償；失敗則破產、退出家庭、觸發家道中落，再處理降級或解散。見 [§17.4](#174-共同負擔盈虧代償機制) |
| 6 | 服刑中被家庭代償 | 可以。代償是破產流程，不是服刑者主動財務操作。見 [§17.4](#174-共同負擔盈虧代償機制) |
| 7 | offer 凍結資產遇清算 | offer 先失效並解凍，再進入清算；凍結資產仍計入總資產。見 [§7.2](#72-交易流程) |
| 8 | 抵押地是否算壟斷持有 | 不算壟斷，仍算持有與總資產。贖回後立即恢復判定。見 [§6.4](#64-區域壟斷) |
| 9 | 中途加入者順位 | v1 不允許開局後中途加入玩家；可觀戰，下一局才能入局。見 [§2](#2-局的生命週期) |
| 10 | 主動退出者地產何時釋出 | 立即依破產規則釋出為無主，但不計入破產結束條件。見 [§12.6](#126-主動退出) |
| 11 | 黑名單清算時能否向玩家借錢 | 只能向金融業職業玩家申請私人放貸；一般玩家不能互借，金融業也可以拒絕。見 [§12.3](#123-還款與違約) |
| 12 | 免租券遇壟斷 | 免租優先；免租期間租金為 0，期滿後才套用壟斷。見 [§7.4](#74-反壟斷保護) |
| 13 | MBA 與減薪疊加 | 乘法疊加：基礎月薪 × 永久加成 × 暫時修正。見 [§9.3](#93-進修) |
| 14 | 股票質押追繳遇服刑 | v1 不適用；股票質押已延到 v1.1。啟用時必須新增「強制賣出可否穿透服刑凍結」規則。見 [§0](#0-v1-範圍) |
