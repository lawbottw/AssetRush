## 1. 名詞定義

| 名詞 | 定義 |
|---|---|
| **局（Game）** | 一次完整的遊戲。由一個 LINE 群組或配對系統建立，2–30 人，結束後不留下任何跨局資產。 |
| **回合（Turn）** | 即時配對型：一位玩家擲骰並行動一次。日常型：一位玩家走完當日一整圈。 |
| **圈（Lap）** | 從起點出發並再次通過起點。**遊戲內 1 圈 = 1 季（3 個月）**，4 圈 = 1 年。通過起點領季薪並開啟[季度事務](#18-季度事務)。 |
| **天（Day）** | 日常型的局長單位。**1 天 = 1 圈 = 1 季**，全局 21 天。 |
| **格（Tile）** | 棋盤上的一個位置。格數依模式與人數而定（即時配對型 16–32、日常型 28/36/48）。 |
| **地產格（Property Tile）** | 對應一個台灣鄉鎮市區、可購買的格。約佔全盤 70–75%。 |
| **功能格（Function Tile）** | 起點、機會、命運、稅捐、監獄、醫院。**只有 6 種**。 |
| **基價（Base Price）** | 一個地產格的購買價，由該鄉鎮真實成交均價換算而來。租金、升級成本、貸款額度皆以此為基準。 |
| **認購（Claim）** | 日常型的購地方式：出價登記，每日 00:00 仲裁（見 [§6.3](#63-出價認購日常型)）。 |
| **季度事務（Quarterly Affairs）** | 通過起點時開啟的財務結算畫面。股票、貸款、進修、買車、保險全在此辦理。 |
| **總資產（Net Worth）** | 現金 + 地產市值 + 股票市值 + 車輛殘值 − 負債。**認購溢價不計入。** |
| **Standing Orders** | 玩家預先設定的自動決策規則，於當日未行動時執行。 |

> **「輪（Round）」一詞已廢除。** 日常型改為非同步後，不再有「全桌各動一次」的同步概念——局長單位是**天**，個人進度單位是**圈**。

## 2. 局的生命週期

```
建立 (lobby)
   │  房主設定：模式、結束門檻、是否公開
   ↓
報名 (recruiting)
   │  2–30 人加入。房主可隨時開始，或到期自動開始
   ↓
開局 (starting)
   │  ① 產生 game_seed → ② 依模式/人數決定棋盤尺寸 → ③ 抽樣生成棋盤
   │  ④ 每人抽身分 → ⑤ 決定回合順位 → ⑥ 計算資產門檻 → ⑦ 公布 hash(server_seed)
   │  ⑧ 立即檢查一次結束條件（防止有人開局即達標）
   ↓
進行中 (active)
   │  即時配對型：即時輪流，直到任一結束條件觸發
   │  日常型：每日循環（各自行動 → 00:00 結算），最多 21 天
   ↓
結算 (settling)
   │  清算所有資產、排名、公開 server_seed
   ↓
結束 (finished)
   │  生成戰報 → 可分享
```

### 2.1 回合順位的決定

開局時，每位玩家由伺服器擲一次 1D100，**由大到小**排定順位。同分則以加入時間先者在前。

**兩種模式下「順位」的意義完全不同：**

| 模式 | 順位的作用 |
|---|---|
| 即時配對型 | **真正的輪流順序**。整局固定不變，破產者的位置直接跳過 |
| 日常型 | **僅為同價競標時的仲裁權**（見 [§6.3](#63-出價認購日常型)），且**每日輪替一位** |

日常型的每日輪替是必要的：如果順位固定，第 1 位玩家會在整整 21 天裡持續享有搶地的優先權，那是不可接受的結構性優勢。

### 2.2 骰子公平性保證（Commit–Reveal）

開局時伺服器產生一個 `server_seed`，並在局內公布其 `SHA-256` 雜湊值。整局所有骰子由

```
roll_n = HMAC-SHA256(server_seed, f"{game_id}:{turn_seq}:{player_id}") mod 6 + 1
```

決定。局結束時公開 `server_seed`，任何人可自行驗算每一次擲骰。

這解決的是「系統是不是偷偷讓我骰爛」的信任問題——在一個朋友之間玩、且有內購的產品裡，這個質疑一定會出現。

## 3. 開局：抽身分

每位玩家獨立抽兩張牌，**互相獨立、不做配對修正**。

### 3.1 家境（Background）— 決定起始資產

決定起始現金，以及可能附帶的股票、地產或學貸。分為負債／普通／小康／中產／富裕五級，機率依台灣家庭財富分配的偏斜形狀設定（詳見 [02](02-game-balance.md#1-家境抽取)）。

**富裕家庭若抽到地產**：該地產必須是本局棋盤上的某一格，由系統隨機指派，且已標記為該玩家所有（等級 L0）。

### 3.2 職業（Occupation）— 決定月薪

決定每經過起點時領取的薪資，以及若干特性（如金融業享證券手續費折扣、公教有退休金、業務收入浮動）。

### 3.3 起手不對稱是刻意的

有人開局就是負債 −$300,000 的服務業，有人是富裕家庭的半導體工程師。這在傳統大富翁裡不存在（大家都是 $1,500）。

我們刻意保留這個不對稱，因為它是這款遊戲**想說的話**：起跑線本來就不一樣。但為了讓遊戲仍然可玩，設計上有三道補償閥：

1. **低起點的向上斜率更陡**——服務業進修門檻最低，轉職到高薪職業的路徑最短。
2. **機會／命運卡對低資產者更有利**——部分事件卡的金額與玩家資產反向掛鉤（如「政府紓困」）。
3. **地產是主要致富路徑，不是薪水**——月薪最高與最低差 2.7 倍，但一格好地產的租金能抵好幾個月薪水。買得早比賺得多重要。

實測驗證見 [02-game-balance.md](02-game-balance.md#11-可玩性推演)。

## 4. 回合結構

**兩種模式的回合單位不同**，但共用同一組階段。

| | 即時配對型 | 日常型 |
|---|---|---|
| 一個回合 = | **擲骰一次** | **走完一整圈**（一日一季） |
| 節奏 | 即時輪流，20 秒倒數 | 非同步，當日任意時間 |

### 4.1 即時配對型：一擲一回合

```
① 擲骰 → ② 移動 → ③ 落點事件 → ④ 自由行動 → ⑤ 結束回合
```

輪到你時完成上述五步，回合權交給下一位。若途中通過起點，額外開啟[季度事務](#18-季度事務)側欄（**不阻塞**其他人，你可以在別人回合時慢慢處理）。

### 4.2 日常型：一日一季

```
每日行動 = 從你目前位置擲骰前進，直到通過起點為止
```

```
① 擲骰 → ② 移動 → ③ 落點事件 ─┐
   ↑                          │  未通過起點 → 繼續擲
   └──────────────────────────┘
                              │  通過起點
                              ↓
④ 季度事務 → ⑤ 自由行動 → ⑥ 今日結束
```

- **位置持續**，不重置到起點。今天走到起點後 3 格，明天就從那裡繼續
- 擲骰次數自然浮動（28 格盤約 8 次、48 格盤約 14 次）
- 沿途事件**自動結算**，只有遇到無主地才停下來問你要不要出價
- **Session 邊界天然乾淨**——永遠結束在起點

**為什麼是「一圈」而不是「N 次擲骰」：** 所有理財動作都集中在通過起點的季度事務（見 [§18](#18-季度事務)），所以**過起點的頻率就是遊戲的心跳**。若四天才過一次，中間三天只是走路付租金。

**「每天 3–5 步」的正確理解是 3–5 個決策，不是 3–5 次擲骰。** 8–14 次擲骰裡大部分是自動通過，真正要動腦的只有「這塊地要不要出價、出多少」。

### 4.3 各階段細節

**① 擲骰**

- 基礎 1D6，持有車輛者獲得移動加成（機車 +1、國產車 +2、進口車 +3）
- 伺服器執行（見 [§2.2](#22-骰子公平性保證commitreveal)），前端只播放動畫
- **服刑或住院中**：不擲骰、不移動。服刑者仍可擲一次骰嘗試出獄

**② 移動**

- 沿棋盤順時針前進
- 移動途中不觸發任何格的事件，只在終點格觸發
- **通過或停留於起點 → 領季薪 + 開啟季度事務**

**③ 落點事件**

依落點類型執行，見[第 5 節](#5-落點類型)。

**④ 自由行動**

| 行動 | 條件 |
|---|---|
| 升級自己的地產 | 現金足夠；**不限升級哪一格**，也不需停在該格 |
| 抵押／贖回地產 | |
| 發起／回應交易邀請 | 對象為任一存活玩家 |
| 發起／回應關係邀請 | 情侶、結婚、加入家庭（見[第 17 節](#17-家庭系統情侶結婚家庭)） |
| 修改 Standing Orders | 隨時，不佔行動 |

**股票、貸款、進修轉職、買車、保險不在這裡** —— 全部移到[季度事務](#18-季度事務)。這讓自由行動階段只剩「地產與人際」兩件事，UI 大幅簡化。

**「不限升級哪一格」是刻意的。** 傳統大富翁要求你停在自己的地才能蓋房，這在日常型下太慢——你可能好幾天才回到自己的地。

**⑤ 結束回合／今日結束**

- 檢查結束條件
- 即時配對型：回合權交給下一位存活玩家
- 日常型：今日行動完成，等待 00:00 全體結算

### 4.4 收入結算的時機

第一版把收入結算放在回合開頭。改制後，**所有收入與扣款都移到通過起點時的季度事務**——因為「一圈 = 一季」，季度結算本來就該發生在季末。

| 每圈（＝每季）自動執行 | 每 4 圈（＝每年）額外執行 |
|---|---|
| 領季薪 | 年終獎金 |
| 副業收入 | 股息配發（持股市值 × 3.2%） |
| 貸款最低應繳（本金 5% + 利息） | 保險費扣繳 |
| 車輛養護費 | 車輛折舊（殘值 −25%） |
| 家用扣繳（若有家庭） | 家庭基金分潤 |
| 在學／服刑／住院狀態 −1 | |

若結算後現金為負，立即進入[清算流程](#124-現金為負時的處理順序)。

## 5. 落點類型

**功能格只有 6 種**，其餘全是地產格（約佔全盤 70–75%）。

| 功能格 | 數量（隨棋盤縮放） |
|---|---|
| 起點（＝季度事務） | 1 |
| 機會 | 1–4 |
| 命運 | 1–4 |
| 稅捐處 | 1–2 |
| 監獄 | 1 |
| 醫院 | 1 |

**證交所、監理站、進修中心三種格已全部移除。** 股票、貸款、進修轉職、買車、保險都改到[季度事務](#18-季度事務)辦理。

移除的理由有兩個：

1. **它們讓「能不能進修」變成運氣問題**——整局沒踩到進修中心，翻身路徑就被骰子封死了。
2. **棋盤應該只講一件事：移動與地產。** 理財是「回到起點坐下來檢視」的事，不是「走到某一格才能做」的事。

棋盤尺寸見 [02 §4.1](02-game-balance.md#41-棋盤尺寸)。

### 5.1 起點（Start）＝ 季度事務

- 通過或停留 → 領取**季薪**（月薪 × 3）並開啟[季度事務](#18-季度事務)
- 停留於此 → 額外獲得 $20,000 的「準時到位獎金」
- **日常型下，通過起點即是今日行動的終點**

> 一圈 = 一季，是讓「繞一圈的收入 ≈ 買下一格的成本」成立的關鍵設定。推導見 [02 §0.1](02-game-balance.md#01-時間單位一圈--一季)。

### 5.2 地產格（Property）

| 情境 | 結果 |
|---|---|
| 無主 | 即時配對型：以**基價**立即購買或放棄<br>日常型：**出價認購**（見 [§6.3](#63-出價認購日常型)）或放棄 |
| 自己的 | 可選擇**升級**（若現金足夠） |
| 別人的（未抵押） | **支付租金**給地主。租金依等級與壟斷狀態計算 |
| 別人的（已抵押） | 不收租 |
| **當日已被認購但未結算** | 仍視為**無主**——不付租金，且你可以加價競標 |
| 別人的（雙方合意） | 支付租金**後**，可額外發起「就地收購」——出價買下該格，地主可拒絕 |

**放棄購買時不進行流拍拍賣。** 傳統大富翁規則有「無人購買則公開拍賣」，我們移除它，因為那需要所有人同步回應。日常型的認購制本身就已經是一種拍賣，只是**非同步**的。

### 5.3 機會 / 命運

抽一張卡並立即執行。兩者的差異：

- **機會（Opportunity）**：偏正面與投機。獎金、投資機會、意外收入、跳格。
- **命運（Fate）**：偏風險與現實。醫療支出、罰款、天災、稅務稽查、監禁。

部分命運卡可由**保險**抵銷（見[第 11 節](#11-保險系統)）。完整卡表見 [02](02-game-balance.md#5-機會與命運卡表)。

### 5.4 稅捐處（Tax Office）

依**總資產累進**課稅，稅金投入「國庫池」。

國庫池的用途：當任何玩家抽到「政府紓困」「消費券」類事件卡時，從國庫池支付。池空則該卡無效果。

這讓稅收在經濟上是**暫存而非銷毀**，維持零和信條。

### 5.5 監獄（Jail）

**走到監獄格本身無害——那是「探監」，什麼事都不會發生。** 只有命運卡會把你關進去。

服刑期間（即時配對型 1 回合、日常型 1–3 天）：

| 可以 | 不可以 |
|---|---|
| ✅ 收租（你的資產照常運作） | ❌ 擲骰、移動 |
| ✅ 交易地產、升級地產 | ❌ **通過起點 → 沒有季度事務** |
| ✅ 回應交易 offer | ❌ 領季薪、買賣股票、申請貸款、進修 |

**坐牢真正痛的地方是失去季度事務**，而不是薪水減半。你走不到起點，所以整段期間領不到季薪、不能調整持股、不能借錢周轉——被關的那幾天，你的財務完全凍結。

**提前出獄**：每個被跳過的回合仍可擲一次骰，**擲出 6 立即出獄**；或支付保釋金 `$20,000 × 剩餘回合`。

刑期：酒駕 2、詐騙 1、逃漏稅 3、內線交易 2（**即時配對型一律壓到 1 回合**——20–40 回合的局關 2 回合等於 10% 的遊戲直接消失）。

**設計意圖**：坐牢懲罰的是**時間與流動性**，不是資產。你的地照收租、股票照漲，只是你動不了、也調不動。

### 5.6 醫院（Hospital）

走到醫院格 = **健康檢查**：支付 $5,000，獲得「下次醫療理賠 +10%」。刻意讓醫院格不是純負面，玩家不必怕它。

住院（即時配對型 1 回合、日常型 1–2 天）由意外／醫療類命運卡觸發：

| 可以 | 不可以 |
|---|---|
| ✅ 收租 | ❌ 擲骰、移動 |
| ✅ 回應交易 offer | ❌ 交易地產、升級地產 |
| | ❌ **通過起點 → 沒有季度事務** |

**醫療險的價值全在這裡**：有保險 → 住院回合數**減半**（無條件捨去，最少 1 回合）＋ 醫療費理賠 80%。無保險住院 2 天＋全額自付，是遊戲中最痛的組合之一。

**自費提前出院**：支付 `$50,000 × 剩餘回合`。有錢就能買回時間——很真實，也讓現金充裕的玩家多一個選項。

### 5.7 監獄與醫院的對照

兩者都是「跳過回合」，但懲罰結構刻意不同：

| | 監獄 | 醫院 |
|---|---|---|
| 收租 | ✅ | ✅ |
| 地產操作 | ✅ | ❌ |
| 季度事務 | ❌ | ❌ |
| 可用保險減免 | ❌ | ✅ 醫療險 |
| 可花錢提前結束 | ✅ 保釋金 | ✅ 自費出院 |
| 懲罰的是 | **流動性** | **沒保險** |

觸發頻率刻意壓低——一年（4 圈）期望住院 0.27 次、入獄 0.16 次。**跳過回合是遊戲中最不好玩的懲罰，它應該是記憶點而不是常態。**

### 5.8 v1 不設的格

免費停車格。它在傳統大富翁裡是「什麼都不會發生」的格，而我們的棋盤每一格都要為「台灣地名」讓路。

## 6. 地產系統

### 6.1 等級與租金

| 等級 | 名稱 | 升級成本 | 停留租金 |
|---|---|---|---|
| L0 | 素地 | — | 基價 × 6% |
| L1 | 套房 | 基價 × 50% | 基價 × 15% |
| L2 | 公寓 | 基價 × 70% | 基價 × 30% |
| L3 | 大樓 | 基價 × 100% | 基價 × 55% |
| L4 | 商辦／飯店 | 基價 × 150% | 基價 × 90% |

升級必須**逐級進行**，不可跳級。升級不需停在該格，也不限升級哪一格。

**購地與升級皆可選擇「以房貸支付」**，當場開立一筆房屋抵押貸款（見 [§12.2](#122-貸款產品)）。

### 6.2 購地方式依模式分岔

| 模式 | 購地 | 為什麼 |
|---|---|---|
| 即時配對型 | **立即成交** | 即時嚴格輪流，同一時間只有一人決策，不可能衝突 |
| 日常型 | **出價認購** | 非同步行動下，兩人可能在同一天走到同一塊無主地 |

### 6.3 出價認購（日常型）

**這是整個日常型設計的樞紐。**

移動、付租金、抽卡、領薪、升級自己的地——這些全都是**可交換的**（誰先誰後結果都一樣）。真正不能並行的**只有一件事**：兩個人搶同一塊無主地。

不必為了那一件事，把 30 個人排成一列。

```
你走到無主地 → 出價認購（≥ 基價，現金當場凍結）
             ↓
       當日 00:00 結算
             ↓
   同格最高價得標 · 同價則當日順位在前者勝 · 落選全額退款
```

| 規則 | 內容 |
|---|---|
| 最低出價 | 基價 |
| 出價時 | 現金**凍結**（不可再用於其他認購或交易） |
| 結算前該格狀態 | 仍為**無主**——別人走到不付租金，且可加價競標 |
| 可見資訊 | **全部公開**：有幾人認購、目前最高價、出價者是誰 |
| 落選 | 全額退款 |
| 每日出價次數 | 不設上限（現金凍結本身就是限制） |

#### ★ 溢價是純沉沒成本

**認購溢價不計入市值、不影響租金、不計入貸款額度。** 租金、抵押、市值一律依**基價**計算。

這是整個機制的平衡核心——加價會自然收斂，不會演變成有錢人無限碾壓。而且它是零和信條的延伸：**多付的錢沒有變成資產。**

溢價也**不可貸款**，銀行只認基價。想加價搶地就得掏現金。

#### 順序感沒有消失，而是變了形

順位不再是「排隊等輪到我」，而是「同價時的仲裁權」，且**每日輪替**。

實際體驗是這樣的：

```
你走到 鹿港鎮（無主 · 基價 $72,000）
⚠ 阿宏今天已出價 $72,000
你的出價：[ $79,000 ]
```

**互動反而比排隊更強。** 你看得到誰在搶、搶多少，並當場決定要不要加價——這比「等 19 個人動完才輪到我」有張力得多，而且很真實，房市本來就是這樣競標的。

### 6.4 區域壟斷

地產格依所屬**縣市**分組。若一位玩家持有某縣市在本局棋盤上的**全部**地產格，該縣市所有地產租金 **×2**。

抵押其中任一格會暫時失去壟斷加成。

以縣市而非六大區域作為壟斷單位，是因為同縣市通常只有 2–5 格（見 [03](03-map-system.md) 的抽樣約束），達成難度剛好；若用六大區域，一組要 4 格以上，太難。

### 6.5 抵押與贖回

| 操作 | 金額 |
|---|---|
| 抵押 | 取得**基價 × 50%** 現金 |
| 贖回 | 支付**基價 × 55%**（含 10% 利息） |

抵押中的地產：不收租、不可升級、不計入壟斷、但**仍計入總資產**（以抵押後淨值計算）。

> **「抵押」與「房屋抵押貸款」是兩回事**，容易混淆。對照見 [§12.2](#122-貸款產品)。

### 6.6 市值與出售

- **市值** = 基價 + 已投入的升級成本總額（不折舊）。**認購溢價不計入。**
- **賣回銀行**：得市值 × 70%。刻意設低，是為了讓玩家間交易比賣回銀行划算，鼓勵互動。
- **賣給玩家**：價格自訂，見[第 7 節](#7-玩家間交易)。

## 7. 玩家間交易

交易是這款遊戲最重要的社交機制。所有交易必須**雙方合意**，系統不介入定價。

### 7.1 可交易標的

一筆交易可包含任意組合：

- 現金
- 地產（含其上的建物等級一併轉移）
- 股票（依股數）
- 車輛
- **「免租券」**：承諾在接下來 N 圈內免收對方租金（系統強制執行，上限 4 圈）

免租券是為了讓交易有非資產的談判籌碼——沒有它，弱勢方常常拿不出東西換。

### 7.2 交易流程

**即時配對型**：
```
A 發起 offer → B 收到即時彈窗 → 60 秒內回應 → 成交 / 拒絕 / 逾時失效
```

**日常型**：
```
A 發起 offer → 進入 B 的待辦匣 → B 下次上線時看到
             → 48 小時 TTL → 成交 / 拒絕 / 逾時失效
```

- 一位玩家同時最多有 **5 筆**待處理 offer（防洗版）。
- offer 送出後，其中的資產被**凍結**（不可用於其他交易或抵押），直到成交或失效。
- 成交瞬間若任一方現金不足，交易自動失效。

### 7.3 就地收購

當你踩到別人的地產並付完租金後，可額外發起一次針對**該格**的收購 offer。這是踩雷之後的補償性互動——「我付了你 $12,000 租金，那不如把這格賣我」。

日常型下這筆 offer 同樣走 48 小時 TTL。

### 7.4 反壟斷保護

若一筆交易會讓某位玩家達成區域壟斷，系統會在**雙方確認前**明確標示警告：「此交易將使 XXX 完成『台北市』壟斷，該區租金翻倍」。

不阻止，只揭露。避免有人因為不熟規則被坑，同時保留談判的樂趣。

## 8. 股票系統

### 8.1 標的

**50 檔，全部沿用真實代號與名稱：**

| 類別 | 數量 | 說明 |
|---|---|---|
| 個股 | 30 | 權值股，涵蓋半導體／電子製造／金融／傳產／電信／食品零售／汽車／航運 |
| 被動式 ETF | 8 | 市值型、高股息、低波動、海外、債券 |
| **主動式 ETF** | **12** | 代號結尾 `A`，2025–2026 台灣最熱門的新品類 |

清單見 [04 §2](04-economy-and-realdata.md#2-股票標的)。

**主動式 ETF 在遊戲中的定位**：波動高於被動 ETF、低於個股，是「不想選股又想要超額報酬」的中間選項。因為掛牌時間短、淨值多在 $10–30 區間，**單價低、入手門檻低，特別適合低起點玩家**——這讓它在設計上承擔了一個具體的功能，而不只是為了跟上市場潮流。

### 8.2 價格：直接使用真實股價，一律 T+1

```
遊戲內股價 = 該檔的真實收盤價（前一交易日）
```

**不做任何映射或縮放。** 台積電在遊戲裡就是兩千多塊一股，中鋼就是十幾塊。

為什麼可以直接用真實價（前一版曾採「統一基準價 $1,000 + 套用漲跌幅」，已廢除）：

| 理由 | 說明 |
|---|---|
| **尺度本來就吻合** | 起始現金 $180,000 可買 74 股台積電、1,734 股 0050、7,722 股主動式 ETF。因為最小單位是「股」不是「張」，高價股一樣買得起 |
| **沉浸感** | 「我買了 100 股台積電」比「我買了 100 單位的虛擬台積電」真實得多 |
| **少一層抽象** | 不需要維護映射層，也不會出現「遊戲裡漲了但真實跌了」的對不上 |
| **T+1 沒有即時壓力** | 價格一天只變一次，玩家不需要盯盤，也不觸碰盤中延遲揭露的規範 |

### 8.3 何時能交易：季度事務

**股票不是棋盤格，也沒有時窗。** 交易併入通過起點的[季度事務](#18-季度事務)——就是你回到起點時順手做的一件事，一圈一次。

證交所格已從棋盤移除。前兩版分別用過「全域開盤鐘」與「過起點後 N 小時個人時窗」，都已廢除：前者要協調所有人，後者仍有時限壓力（「我上線時剛好過期」）。

**日常型下三件事天然對齊：**

```
1 天  =  1 圈  =  1 次季度事務  =  1 次 T+1 價格更新
```

每天恰好一次交易機會，不早不晚，也不需要盯任何時鐘。

**即時配對型的季度事務是非阻塞側欄**——你可以在別人回合時慢慢處理，不卡住牌桌。

### 8.4 價格何時推進

**兩種模式規則一致：每圈推進一個真實交易日。** 休市日沿用前一交易日收盤價。

- 日常型：1 圈 = 1 天，天然對齊真實日曆
- 即時配對型：整局在真實世界只過了 20–45 分鐘，若不推進價格則股價紋風不動、股票淪為呆滯資產。改為每圈跨一個交易日後，一局能回放 4 天的真實走勢。開局時決定起始日期

### 8.5 交易規則

| 項目 | 數值 |
|---|---|
| 最小單位 | **1 股**（不設張，降低門檻） |
| 手續費 | **0.1425%**，最低 $20。金融業職業享 5 折 |
| 證交稅 | **0.3%**，僅賣出時課徵 |
| 單一標的持有上限 | 總資產的 **60%** |
| 融資融券／放空 | **不開放** |

**不可放空、不可融資融券**——這是遊戲，不是模擬器。唯一的槓桿管道是[股票質押](#122-貸款產品)，且它帶有追繳機制。

單一標的 60% 上限是為了防止 all-in 賭博式玩法毀掉遊戲節奏。

### 8.6 股息

每 **4 圈**（＝1 遊戲年）配息一次，金額為持股市值的 **3.2%**（約當台股年均殖利率）。不逐檔區分殖利率——這是刻意的簡化，避免玩家為了股息去背四十檔標的的配息政策。

### 9.1 職業層級

職業分三級，決定轉職的自由度：

| 層級 | 職業 |
|---|---|
| T1 | 服務餐飲、製造技術員、行政文書、業務、自由接案 |

### 9.2 轉職

- **跨層級向上**：必須先完成對應的**進修**。
- **向下**：隨時可以，但不會有人想。

### 9.3 進修

| 課程 | 學費 | 在學圈數 | 解鎖 |
|---|---|---|---|
| 職訓／證照班 | $60,000 | 2 | T1 → T2 |
| 在職專班 | $250,000 | 3 | T2 → T3 |
| MBA | $800,000 | 4 | T3，且月薪 +20% 永久加成 |

**在學期間**：
- 季薪減半（進修排擠工時）
- 仍正常擲骰移動、收租、交易、買賣股票
- 每次通過起點時剩餘圈數 −1

進修是低起點玩家的主要翻身路徑，但代價是好幾季的收入下降——日常型下就是好幾天的相對落後。這個取捨是設計的核心張力。

> **改制後進修變強了。** 第一版把進修綁在「踩到進修中心格」，等於翻身路徑要看骰運；現在只要回到起點就能報名。加上日常型有 21 圈（原本 7 圈），回本時間相對局長的佔比大幅下降。**P1 模擬必須確認進修沒有變成必選項。**

### 9.4 副業

每局限選一項，選定後不可更換。於季度事務選擇，收益在每次通過起點時入帳。

| 副業 | 啟動成本 | 每圈收益 | 風險 |
|---|---|---|---|
| 網拍代購 | $30,000 | $3,000 | 無 |
| 團購主 | $80,000 | $8,000 | 10% 機率該回合收益歸零（貨到不領） |
| 直銷 | $150,000 | $5,000 + 每位「下線」$2,000 | 每圈 8% 機率觸發「囤貨」，扣 $50,000 |
| 接案外包 | $0 | 1D6 × $2,000 | 收益全隨機 |
| 收租代管 | $200,000 | 自己所有地產租金收入的 +10% | 無 |

**直銷的下線機制**：落於機會格時有機率「拉到下線」（最多 3 位），下線是 NPC，不影響其他玩家。這個設計是刻意的諷刺——高承諾、高波動、看似有槓桿，實際期望值不特別高。

## 10. 車輛系統

買賣車輛在[季度事務](#18-季度事務)辦理（監理站格已從棋盤移除）。

| 車種 | 售價 | 移動加成 | 每圈養護 | 折舊 |
|---|---|---|---|---|
| 無 | — | 1D6 | — | — |
| 機車 | $80,000 | +1 | $1,000 | 每 4 圈 −25% 殘值 |
| 國產車 | $600,000 | +2 | $5,000 | 同上 |
| 進口車 | $1,800,000 | +3 | $15,000 | 同上 |

### 10.1 兩種模式下車的意義完全不同

| | 即時配對型 | 日常型 |
|---|---|---|
| 回合數 | 固定（由目標時長決定） | 每天固定走完一圈 |
| 走得快代表 | **多繞圈** → 多領薪水、多掃無主地 | **用更少擲骰走完同一圈** → 沿途落點變少 |
| 好處 | 更多季度事務、更多搶地機會 | 少踩別人的地、少付租金 |
| 壞處 | 更常踩到高租金地產、養護費失血 | **也少了買地與抽卡的機會**、養護費失血 |

即時配對型的邏輯與經典大富翁一致：走得快 ≠ 走得好，棋盤上高等級地產密集時走慢反而安全。

> ⚠️ **日常型的車輛價值待驗證。** 「一日一季」改制後，每天固定走完一圈，移動加成不再增加繞圈數，只是讓你**用更少落點走完這一圈**——這是完全不同的價值主張，第一版的平衡推導已失效。
>
> P1 模擬必須回答：在日常型下，「少踩雷」是否值得養護費？若證實無意義，考慮在日常型停用車輛系統，或明確重新定位為「風險規避道具」。

### 10.2 出售

- 於季度事務出售：得殘值 × 90%
- 破產清算時：以殘值 × 70% 計入

## 11. 保險系統

投保與解約在[季度事務](#18-季度事務)辦理。保費**每 4 圈**（＝1 遊戲年）自動扣繳一次。

| 險種 | 保費／年 | 保障 |
|---|---|---|
| 醫療險 | $12,000 | 命運卡的醫療類支出，理賠 80% |
| 意外險 | $8,000 | 命運卡的意外類支出，理賠 100%，上限 $200,000 |
| 住宅火險 | $6,000 | 天災類事件對地產的損害，理賠 100% |
| 責任險 | $15,000 | 罰款、訴訟類支出，理賠 60% |

未投保時，天災事件可能直接讓一格地產**降一級**（如 L3 → L2），且不退還升級成本。這是保險存在的意義——不是為了省小錢，是為了避免資產結構被一張卡打壞。

保險是[品牌置入](00-product-overview.md#72-品牌置入次要但天花板高)最自然的槽位。

## 12. 借貸與破產

### 12.1 核貸的原則

**銀行看的是你有什麼，不是你需要多少。**

不同資產結構有不同的融資管道：有薪水的人靠信用貸款、有地產的人靠抵押、有股票的人靠質押。這讓「我現在缺錢該怎麼辦」在每個玩家身上有不同答案。

**申請與還款在[季度事務](#18-季度事務)辦理**，唯二例外：

| 例外時機 | 可用產品 |
|---|---|
| **購地或升級時**當場選擇「以房貸支付」 | 房屋抵押貸款 |
| 清算流程中系統詢問是否借錢避免破產 | 民間信貸 |

購地貸款不含[認購溢價](#-溢價是純沉沒成本)——銀行只認基價，想加價搶地就得掏現金。

### 12.2 貸款產品

| 產品 | 核貸依據 | 額度 | 利率／圈 |
|---|---|---|---|
| **信用貸款** | 薪資 | `月薪 × 倍數`（T1 = 16、T2 = 20、T3 = 22） | 2.0% |
| **房屋抵押貸款** | 地產 | 未抵押地產市值 × 60% | 1.2% |
| **股票質押** | 持股 | 持股市值 × 50% | 1.5% |
| **就學貸款** | — | 固定 $300,000（僅負債家庭起手持有） | 0.5% |
| **民間信貸** | 無審核 | 缺口金額，隨借隨有 | **8.0%** |

**信用貸款的 22 倍上限**錨定台灣金管會對銀行無擔保債務的「月薪 22 倍」規範。職業層級越高倍數越高——這是真實的，也讓[進修轉職](#9-職業、進修、轉職、副業)多了一個薪水以外的回報：**你的融資能力也跟著升級。**

**房貸 vs 抵押的差異**（容易混淆）：

| | 抵押（見 [§6.5](#65-抵押與贖回)） | 房屋抵押貸款 |
|---|---|---|
| 取得 | 基價 × 50% | 市值 × 60% |
| 地產還能收租嗎 | ❌ | ✅ |
| 地產可出售嗎 | ✅（贖回後） | ❌（被設定為擔保品） |
| 成本 | 贖回時 +10% | 每圈 1.2% 利息 |

**股票質押的追繳機制**：若持股市值跌到貸款餘額的 **1.3 倍**以下，觸發追繳——需補現金或被強制賣出持股。這是遊戲裡唯一的槓桿風險，刻意保留，因為它是股票玩法最真實的一課。

**民間信貸**利率是信用貸款的 4 倍，無審核、隨借隨有。它存在的意義是給玩家一個「明知不該但現在必須」的選擇——它通常是破產前的最後一步，而不是解方。UI 上必須明確標示風險，**不做任何誘導**。

職業加成：金融業信貸利率 −0.5%／圈；公教人員信貸倍數 +4（真實世界銀行確實偏好公教）。

### 12.3 還款與違約

- **每圈自動扣繳最低應繳** = `餘額 × 5% + 累計利息`
- 隨時可提前還款，無違約金
- **總負債上限** = 總資產 × 1.5（民間信貸除外）

現金不足以支付最低應繳 → **違約**：

| 違約次數 | 後果 |
|---|---|
| 每次 | 利率 +1.0%／圈，2 圈內不得申請新的信用貸款 |
| 累計 3 次 | **信用黑名單**——僅剩民間信貸可用 |

違約不會立即破產，但會讓後續融資成本螺旋上升。這是真實的債務陷阱，也是遊戲想傳達的東西之一。

### 12.4 現金為負時的處理順序

當任一階段結束後現金為負，玩家進入**清算流程**，依序自動執行直到現金 ≥ 0：

1. 賣出股票（由持有市值最小的標的開始）
2. 抵押地產（由基價最低的開始）
3. 出售車輛
4. 賣出地產給銀行（市值 × 70%，由基價最低的開始）

### 12.5 強制清算

若上述四步全部執行完畢後現金仍為負：

**若你有家庭／伴侶** → 先進入[隊友代償](#174-共同負擔盈虧代償機制)。代償成功則不破產。

代償失敗，或你本來就沒有隊友 → **宣告破產**。

破產玩家：
- 立即退出本局，不再參與回合
- 名下所有資產歸還「無主」狀態（不歸給債權人）
- 計入結束條件的破產人數
- 公教職業保留 $200,000「退休金」（不計入本局，僅為結算排名用）

**資產歸還無主而非歸債權人**，是為了避免「打死一個人就吃掉他全部家產」的滾雪球，讓局勢不會在中期就鎖死。這是對零和信條的一個刻意例外，理由是遊戲體驗優先。

### 12.6 主動退出

日常型下允許主動退出（現實中人會離職、會出國）。主動退出**視同破產**處理，但不計入結束條件的破產人數——避免有人為了結束遊戲而故意退出。

## 13. Standing Orders（預設指令）

### 13.1 設計理由

日常型下你可能整天沒上線。系統必須替你走完那一圈，否則局會停擺。

但「逾時就 AI 代打」不行——被系統亂打的玩家會有強烈的失控感，那是流失的直接原因。

**Standing Orders 的解法是：託管執行的是玩家自己事先設定的策略。** 你被託管了，但打出來的是你的意志。

### 13.2 可設定的規則

玩家可**隨時**設定，免費版最多 3 條，付費版 8 條。

| 類別 | 可設定項 |
|---|---|
| **出價** | 「基價 < X 才出價」／「只出基價，絕不加價」／「加價上限 +N%」／「只買 [指定縣市]」／「一律不出價」 |
| 升級 | 「現金 > X 時自動升級最高租金的地產」／「一律不升級」 |
| 交易 | 「自動拒絕所有 offer」／「自動接受淨值為正且 > X 的 offer」／「一律保留待我決定」 |
| 股票 | 「季度事務自動不動作」／「單一標的跌破成本 X% 自動賣出」 |
| 保險 | 「保費到期自動續約」／「現金 < X 時自動解約」 |
| 現金底線 | 「保留至少 $X 不動用」（優先於所有其他規則） |

**加價規則是新機制的重點。** 認購制下「要不要加價、加多少」是每天最重要的決策，託管必須能表達你的態度——保守的人設「只出基價」，積極的人設「加價上限 +20%」。

### 13.3 執行優先序

```
① 檢查現金底線 → ② 強制項（付租金、扣款，無法規避）
→ ③ 依 Standing Orders 決定出價／升級
→ ④ 未被規則覆蓋的決策一律「不動作」
```

**未設定 = 不動作**，而非「系統幫你判斷」。保守是安全的預設。

### 13.4 使用者體驗

- 首次開局時強制引導設定至少 1 條（出價規則）
- 每次被託管後，推播附上「這是系統依你的設定做的決定」＋ 一鍵調整入口
- 局內隨時可見「若我今天沒上線，會發生什麼」的預覽

## 14. 回合推進

### 14.1 即時配對型：即時輪流

- 每回合 **20 秒**倒數
- 倒數歸零 → 執行 Standing Orders → 推進
- 連續 3 次逾時 → 標記為「掛機」，後續回合倒數縮短為 8 秒

### 14.2 日常型：非同步 + 每日結算

**沒有回合時窗，沒有排隊。**

```
當日任意時間 → 你一次走完整圈 → 完成
                    ⋮
              （其他人也各自在任意時間行動，互不阻塞）
                    ⋮
每日 00:00 → 結算 → 群組推播「昨日戰況」
```

| 為什麼可以並行 | 說明 |
|---|---|
| 移動 | 各走各的，互不影響 |
| 付租金 | A 付給 C 跟 B 付給 C 誰先誰後，結果一樣 |
| 抽卡、領薪、扣款 | 只影響自己 |
| 升級自己的地 | 不與任何人衝突 |
| **買無主地** | ⚠️ **唯一的衝突點** → 由[出價認購](#63-出價認購日常型)處理 |

**這是整個設計的核心洞察：不必為了一件不能並行的事，把所有事都排成隊。**

### 14.3 每日 00:00 結算

```
① 仲裁所有認購（最高價得標，同價則當日順位在前者勝）
② 落選者全額退款
③ 當日未行動者 → 執行 Standing Orders 自動走完一圈
④ 順位輪替一位
⑤ 檢查結束條件
⑥ 生成「昨日戰況」推播到 LINE 群組
```

**⑥ 是這個機制的意外收穫。** 每天早上群組收到一則昨日戰報（誰買到什麼、誰付了誰多少租金、誰破產了），這是比「輪到你了」更強的社交鉤子——它給了群組**共同的話題**，而不只是個人的提醒。

### 14.4 可預測性從哪來

第一版靠「你的回合大概每天 19:30」建立習慣。非同步後這個錨點消失了，改由三件事取代：

| 錨點 | 內容 |
|---|---|
| **每日戰報** | 固定 00:00 結算、早上推播，形成日曆節奏 |
| **今日進度** | 「今天 12 / 30 人已行動，你還沒動」 |
| **認購倒數** | 「你對鹿港鎮的出價將於 4 小時 20 分後結算」 |

玩家不再需要在特定時刻上線，只需要**每天找個時間玩一次**——這正是日常型該有的樣子。

## 15. 結束條件與勝負判定

### 15.1 觸發條件（任一滿足即結束）

| 條件 | 即時配對型 | 日常型 |
|---|---|---|
| 任一玩家總資產達標 | **動態門檻**（≈ $2.1M–$5.2M，依圈數） | **動態門檻**（≈ $8.2M） |
| 破產比例 | ≥ 20% 玩家破產（>20 人桌為 30%） | 同左 |
| 局長上限 | **2–12 圈**（由目標時長決定） | **21 天 ＝ 21 圈** |
| 時間上限 | 目標時長 × 1.5 | 21 天 |

**資產門檻是動態的，不是固定值。** 圈數在新架構下是可變的（即時配對型 2–12 圈、日常型 21 圈），經濟規模差 5 倍以上，單一常數無法同時服務兩者。

```
預估薪資注入 = 圈數上限 × 全桌平均季薪

資產門檻 = max( (開局全桌平均總資產 + 預估薪資注入) × 2.5 ,
                開局全桌最高總資產 × 1.6 )
```

**第一項自動隨局長縮放**，不需要人工調參——這取代了第一版的 M 值制。

**第二項是必要的下界**：一位「富裕家庭 + 半導體工程師」起始總資產約 $2,350,000，沒有這條，短局會在第 1 回合就結束。因此也必須**在開局後立即檢查一次結束條件**。

門檻於開局時計算一次並固定，局內全程可見。房主可在 ±50% 範圍內調整。完整推導見 [02 §4.3](02-game-balance.md#43-資產結束門檻)。

破產比例以**開局人數**為分母，無條件進位。2–4 人桌時 1 人破產即觸發（`ceil(4 × 0.2) = 1`）；超過 20 人的桌門檻放寬至 30%。

局長上限亦可由房主在 ±50% 範圍內調整。

### 15.2 勝負判定

結束時依**總資產**排名：

```
總資產 = 現金
       + Σ 地產市值（抵押中的以淨值計）
       + Σ 股票市值（以最後一次更新價計）
       + 車輛殘值
       − 貸款餘額（含累計利息）
```

### 15.3 結算與戰報

結算階段：
1. 凍結所有動作
2. 公開 `server_seed`（供驗算骰子）
3. 計算最終排名
4. 由 `game_events` 事件流生成**戰報**

戰報包含（自動選取最戲劇性的片段）：
- 最終排名與資產曲線圖
- 「本局最大一筆租金」
- 「最早破產的人」與「撐最久的人」
- 「地產大亨」（持有最多格）
- 「股神／韭菜」（股票總損益極值）
- 「最活躍交易者」
- 每個人的個人化一句話總結

戰報是一張 Flex Message 圖卡，可一鍵分享到其他 LINE 群組——這是產品的主要擴散點（見 [00](00-product-overview.md#病毒擴散機制)）。

## 16. 兩種模式的參數差異

**兩種模式共用同一套規則引擎與同一份數值表**，差異只在下表列出的參數。這是刻意的架構決策——維護兩套規則會讓平衡工作量翻倍。

| 參數 | 即時配對型 | 日常型 |
|---|---|---|
| 人數 | 2–8 | 2–30 |
| **回合單位** | **擲骰 1 次** | **走完一整圈**（一日一季） |
| 推進方式 | 即時嚴格輪流 | **非同步**，當日任意時間 |
| 回合時限 | 20 秒 | 一整天（00:00 結算） |
| 棋盤 | 16–32 格（依目標時長與人數自動配置） | 28 / 36 / 48 格（依人數） |
| 局長 | 2–12 圈 或 目標時長 × 1.5 | 21 天 ＝ 21 圈 |
| **購地方式** | 立即成交 | **出價認購**，每日仲裁 |
| 順位的作用 | 真正的輪流順序 | 同價競標的仲裁權，**每日輪替** |
| 監禁／住院上限 | 1 回合 | 3 回合 |
| 交易 offer TTL | 60 秒 | 48 小時 |
| Realtime 連線 | 常駐 WebSocket | 不常駐（推播 + 拉取） |

**兩者共用同一套規則引擎與同一份數值表。** 季度事務、股票、貸款、保險、家庭系統、結束門檻公式全部一致——差異只在上表。

### 16.1 兩種模式的策略差異是刻意的

圈數差距極大（即時配對型 2–12 圈 vs 日常型 21 圈），最優策略天然分岔：

| | 即時配對型 | 日常型 |
|---|---|---|
| 進修 | 短局來不及回本 | 明顯值得（21 圈） |
| 起手優勢 | **決定性**——低起點幾乎追不上 | 可被翻盤 |
| 搶地 | 立即成交，先手優勢明顯 | 出價競標，錢比順序重要 |
| 主要致富手段 | 搶地 + 壟斷 | 進修轉職 + 長期地產經營 |
| 適合誰 | 想一次爽完 | 想每天玩三分鐘 |

低起點玩家在即時配對型明顯劣勢，這點必須在模式選擇的 UI 上誠實說明——**日常型才是翻身者的主場**。

### 16.2 即時配對型的目標時長自動配置

房主只選「想玩多久」（20 / 30 / 45 分），系統依人數反推格數與圈數。

**因為時長 = 回合數 × 人數，固定 preset 給不了固定時長**——同一組設定 4 人 18 分、8 人 34 分。讓玩家自訂他真正在乎的東西（時間），而不是他無法推理的東西（格數／圈數）。

大廳即時顯示預覽：`6 人 · 22 格 · 4 圈 · 約 30 分鐘`，人數變動即時重算。

完整公式與各組合輸出見 [02 §4.2](02-game-balance.md#42-即時配對型目標時長自動配置)。

## 17. 家庭系統（情侶／結婚／家庭）

玩家可在局進行中與其他玩家組成關係，**共同負擔盈虧**。上限 8 人。

### 17.1 核心設計：組隊改變的是「風險」，不是「勝利條件」

如果組隊能直接提升勝率，8 人抱團就會變成唯一解，遊戲就毀了。

所以設計是：

| 你得到 | 你付出 |
|---|---|
| 隊內互不收租（或減半） | 每圈繳「家用」 |
| **破產前隊友強制代償** | 稅率加成（隊伍越大越高） |
| 租金收入按持份分潤 | 分潤稀釋你的個人資產 |
| | 隊友代償失敗時全隊「家道中落」 |

**勝負仍以個人總資產排名**（額外顯示家庭排名），結束條件的資產門檻也看個人、不看家庭總和。組隊不能靠人多直接衝線。

這也符合主題：**家庭讓你更安全，但也更難暴富。**

### 17.2 三種關係層級

| 關係 | 人數 | 成立成本 | 隊內租金 | 家用／圈 | 分潤 | 稅率加成 | 代償義務 |
|---|---|---|---|---|---|---|---|
| **情侶** | 2 | 免費 | ×0.5 | 季薪 5% | 10% | — | 30% |
| **已婚** | 2 | 見下 | **免收** | 季薪 10% | 25% | +10% | 100% |
| **家庭** | 3–4 | 每人 $100,000 | 免收 | 季薪 15% | 30% | +20% | 100% |
| **大家庭** | 5–8 | 每人 $100,000 | 免收 | 季薪 20% | 35% | +40% | 100% |

家庭與大家庭**必須以一對已婚成員為核心**才能成立。

**情侶是免費且可隨時分手的輕量入口**，讓玩家先體驗機制再決定要不要投入。

### 17.3 結婚與離婚

**結婚**二選一：

| 方式 | 費用 | 附帶 |
|---|---|---|
| 辦婚禮 | $300,000 | 收到親友禮金 = `全桌人數 × $12,000` |
| 公證結婚 | $50,000 | 無 |

25 人以上的局辦婚禮才回本（$300,000 vs 25 × $12,000 = $300,000）。**人多的局辦婚禮才划算——這個取捨本身就很真實。**

**離婚**：律師費 $150,000 ＋ 雙方總資產**對分**。代價高到讓「要不要結婚」是個真決策，而不是隨手點的按鈕。

整局最多變更關係 **2 次**（含分手、離婚、加入或退出家庭），防止玩家依局勢反覆重組。

### 17.4 共同負擔盈虧：代償機制

**這是整個系統存在的意義。**

當某位成員完成[四步清算](#124-現金為負時的處理順序)後現金仍為負：

```
① 家庭基金代付
      ↓ 不足
② 隊友按持份強制扣款（單次上限為其現金的 50%）
      ↓ 仍不足
③ 該成員破產 + 全隊「家道中落」：所有成員損失 10% 現金
```

**單次代償上限 50%** 是為了避免一人拖垮全家。**家道中落**則確保組隊不是無風險的——你救不起隊友，全家一起受傷。

### 17.5 家庭基金

- 每圈收入結算時，每位成員繳交季薪的家用比例進基金
- 成員的租金收入按分潤比例進基金
- **每 4 圈與局末**按持份分配，持份 = 你累計繳交額佔基金總繳交額的比例

賺得多的人繳得多、分得也多，但實質上是把個人收益攤平給全隊——這是「共同負擔盈虧」的正向那一半。

### 17.6 反濫用限制

| 限制 | 理由 |
|---|---|
| **隊內不可轉移地產**（現金、股票可以） | 否則 8 人可把地產集中到一人身上刷[區域壟斷](#64-區域壟斷)，破壞壟斷機制的難度設計 |
| 上限 8 人 | 8 人可能持有半數地產，隊內免租的覆蓋面再大就會對外部玩家形成無解的租金牆 |
| 稅率加成隨規模遞增 | 主要平衡閥 |
| 家用比例隨規模遞增 | 次要平衡閥 |

**平衡監控**：P1 蒙地卡羅必須驗證組隊者與單身者的勝率差距 < 8 個百分點。若組隊明顯較強，優先調高稅率加成與家用比例，**而非削弱代償**——代償是這個系統存在的理由。

### 17.7 邀請流程

```
A 發出關係邀請 → B 收到 → 同意 / 拒絕 / 逾時失效
```

TTL：日常型 48 小時、即時配對型 60 秒。與[交易 offer](#72-交易流程) 共用同一套待辦匣。

機會卡 **O22「聯誼認識新朋友」** 可讓你立即向任一玩家發出情侶邀請且免除成立成本——這是組隊系統的引導入口，讓沒注意到這個功能的玩家有機會被推一把。

## 18. 季度事務

**通過起點 = 這一季的財務結算日。** 所有理財動作集中於此。

```
┌────────────────────────────────┐
│ 通過起點 · 第 3 季（第 3 天）    │
├────────────────────────────────┤
│ ✓ 季薪              +$174,000  │
│ ✓ 租金收入           +$88,200  │
│ ✓ 副業（網拍代購）    +$3,000  │
│ − 貸款最低應繳       −$42,500  │
│ − 車輛養護           −$5,000   │
│ − 家用（已婚 10%）   −$17,400  │
├────────────────────────────────┤
│ 本季可辦理（各限一次）：         │
│   ▸ 股票交易     2330 ▲2.3%   │
│   ▸ 貸款申請 / 還款             │
│   ▸ 進修 / 轉職                 │
│   ▸ 買車 / 賣車                 │
│   ▸ 保險投保 / 解約             │
│   ▸ 副業選擇（每局限一次）       │
├────────────────────────────────┤
│      [ 完成，繼續下一季 ]       │
└────────────────────────────────┘
```

### 18.1 為什麼把理財全部集中在這裡

第一版把股票、車輛、進修各自綁在證交所格、監理站格、進修中心格上。那有三個問題：

| 問題 | 說明 |
|---|---|
| **翻身路徑被骰運封死** | 整局沒踩到進修中心，低起點玩家就沒有翻身管道 |
| **UI 囉嗦** | 這些動作散在自由行動階段，每回合都要問玩家一次 |
| **棋盤格位被佔用** | 3 格功能格 = 3 個台灣鄉鎮上不了場 |

集中之後：

- **棋盤只講一件事**：移動與地產
- **理財有固定節奏**：一季一次，符合現實隱喻（每季檢視一次財務）
- **地產格變多**，全台涵蓋度提升
- **進修不再靠運氣**

### 18.2 這也決定了日常型的節奏

既然過起點是唯一的理財時機，**過起點的頻率就是遊戲的心跳**。

這正是「[一日一季](#42-日常型一日一季)」的由來——若四天才過一次起點，中間三天只是走路付租金，玩家沒有任何有意義的決策可做。

### 18.3 兩種模式的呈現差異

| | 即時配對型 | 日常型 |
|---|---|---|
| 何時開啟 | 通過起點時 | 通過起點時（＝今日行動終點） |
| 是否阻塞他人 | **否**，非阻塞側欄 | 不適用（非同步） |
| 處理時間 | 可在別人回合時慢慢處理 | 沒有時限 |

**即時配對型的非阻塞設計很重要。** 若季度事務會卡住牌桌，一個猶豫的玩家就能讓其他 5 人等 60 秒。改為側欄後，它反而利用了「看別人回合」的空檔。

### 18.4 服刑與住院期間沒有季度事務

被關或住院時走不到起點，所以整段期間**領不到季薪、不能買賣股票、不能借錢周轉**。

這是[監獄與醫院](#57-監獄與醫院的對照)真正痛的地方——比薪水減半更實質。你的財務被完全凍結。
