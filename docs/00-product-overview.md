# 00 — 產品總覽

> AssetRush｜多人同步大富翁．台灣真實金融版
> 文件版本 v0.1｜2026-08-06

---

## 1. 一句話定位

**把實體大富翁桌遊搬進 LINE 群組**——保留「一人做完、下一人才骰」的完整回合順序與零和經濟，接上台灣真實股市、實價登錄房價與薪資結構，讓一群朋友每天花 3 分鐘玩一個月。

---

## 2. 我們不做什麼（差異化的定義來自排除法）

現有大富翁類手遊幾乎都往同一個方向長：體力值、掛機養成、抽卡、攻擊別人城市、公會戰。這些機制的共同點是**經濟不再共生**——你的傷害值憑空生成，我的損失不會變成你的收入。那已經不是大富翁了，只是套了大富翁皮的放置遊戲。

| 現有手遊常見機制 | AssetRush |
|---|---|
| 體力／行動力限制 | ❌ 不做。日常型的節奏由回合順序決定，不由體力決定 |
| 掛機／離線收益養成 | ❌ 不做。離線只會走 Standing Orders，不會憑空長錢 |
| 攻擊／破壞別人的建築 | ❌ 不做。玩家之間只有交易、租金、市場競爭 |
| 抽卡強度牆 | ❌ 不做。內購僅限造型與便利性，不賣數值 |
| 憑空生成的傷害／獎勵 | ❌ 不做。**每一塊錢都有來源與去向** |
| 公會戰／PVP 排名賽季 | ❌ 不做 v1 |

**核心信條：經濟共生（Zero-Sum Economy）。**
A 踩到 B 的飯店付 $2,000，帳上就是 A −$2,000、B +$2,000。系統不憑空創造也不憑空銷毀貨幣，唯二的例外是「薪資／利息注入」與「稅捐回收」，兩者都必須在數值文件中列明並保持長期平衡。

## 3. 兩種模式

### 3.1 日常型（Daily）— 主打

| 項目 | 設定 |
|---|---|
| 人數 | 2–30 人（通常是一個 LINE 群組） |
| 節奏 | **每日固定擲骰次數**——每天用完 8–14 次擲骰額度，約 3–5 分鐘 |
| 局長 | **21 天 ＝ 21 圈** |
| 回合推進 | **非同步**，當日任意時間行動；每日 00:00 結算 |
| 購地 | **出價認購**，同格最高價得標 |
| 適用場景 | 同事群、家族群、大學同學會——不用喬時間 |

日常型是產品的重心。它解決的是「大家想一起玩桌遊但永遠喬不到時間」這件事。

**「每日固定擲骰」的意思是：** 每天你的行動就是從目前位置擲骰固定次數。沿途事件自動結算，遇到無主地或休閒格才停下來問你要怎麼處理；通過起點時辦理[季度事務](01-game-rules.md#18-季度事務)（領薪、股票、貸款、進修），但不會因此結束今天，剩餘擲骰額度仍可繼續使用。

**沒有「輪到你」的等待。** 30 人的群組裡，每個人都可以在自己方便的時間玩，互不阻塞——因為除了「搶同一塊地」以外，所有動作都是可交換的。而搶地由每日的競標仲裁處理。

### 3.2 即時配對型（Blitz）

| 項目 | 設定 |
|---|---|
| 人數 | 2–8 人（即時配對或群組限時開局） |
| 節奏 | **房主選 20 / 30 / 45 分鐘**，系統依人數自動配置棋盤 |
| 局長 | 2–12 圈（由目標時長反推） |
| 回合推進 | 嚴格序列，每回合 20 秒倒數 |
| 購地 | 立即成交 |
| 適用場景 | 週末晚上、聚會現場、想一次爽完 |

**為什麼讓玩家選時間而不是選圈數：** 時長 = 回合數 × 人數，所以固定設定給不了固定時長（同一組設定 4 人 18 分、8 人 34 分）。讓玩家自訂他真正在乎的東西。

### 3.3 共通規則

兩種模式**共用同一套規則引擎與同一份數值表**——季度事務、股票、貸款、保險、家庭系統、結束門檻公式全部一致。差異只在推進方式與棋盤尺寸（見 [01 §16](01-game-rules.md#16-兩種模式的參數差異)）。這是刻意的設計——維護兩套規則會讓平衡工作量翻倍。

## 4. 局的獨立性

**每個群組開的每一局都是全新獨立的局。** 沒有跨局繼承、沒有帳號等級、沒有養成。

這條規則的代價是失去「長期留存鉤子」，但換來三件更重要的事：

1. **新人零門檻加入。** 群組裡第 20 個人今天才裝，明天開新局跟大家站在同一起跑線。這對 LINE 群組擴散是決定性的——沒有人想加入一個「別人已經玩三個月、我永遠追不上」的遊戲。
2. **平衡可迭代。** 沒有跨局經濟，改數值不會毀掉誰的存檔。
3. **它才是桌遊。** 你不會因為上次玩大富翁贏了，這次就多發 $500 起始資金。

留存改用**局的節奏**驅動：一局 21 天結束，戰報發到群組，有人喊「再一局」。這是實體桌遊的留存模型，也是我們要的。

設計原則是**影射式耦合**：遊戲跟著真實世界的「節奏」走（今天台積電漲 2%，遊戲裡的 2330 也漲 2%），但不使用真實股價的絕對值，也不提供任何投資建議。這讓遊戲有「今天股市紅通通我也賺了」的話題性，同時不觸碰金融資訊服務的法遵邊界。

## 6. 雙軌通路

```
                    ┌─────────────────────────┐
                    │   同一個 Next.js 應用     │
                    └─────────────────────────┘
                       ↙                    ↘
        LINE Mini App (LIFF)          獨立網站 (PWA)
        · 群組一鍵開局                 · 可加到主畫面
        · LINE 登入即身分              · Email／Google 登入
        · 戰報 Flex Message 分享       · 完整桌機體驗
        · 主要獲客管道                 · 主要留存管道
```

### 為什麼是 LINE

台灣人的社交圖譜幾乎完全存在 LINE 群組裡。一個「大學同學會」群組已經是一張現成的玩家名單，不需要我們做好友系統、不需要邀請碼、不需要買量。開局的動作是「在群組裡貼一張卡片，大家點進來」。

獲客成本趨近於零，代價是我們必須接受 LINE 的技術限制（WebView、審查、平台抽成）——這些在 [06-architecture.md](06-architecture.md) 逐項處理。

### 病毒擴散機制

1. **開局邀請**：群組內貼 Flex Message 卡片，一鍵加入
2. **每日戰報**：每天早上群組收到一則「昨日戰況」（誰搶到哪塊地、誰付了誰多少租金、誰破產了）——**比個人提醒更強的鉤子**，因為它給了群組**共同的話題**
3. **未行動提醒**：當天還沒玩的人晚上收到個人推播（可關）
4. **局末戰報**：自動生成一張「本局大事記」圖卡（誰破產、誰買下信義區、最大一筆租金），透過 `liff.shareTargetPicker()` 分享到其他群組——**這是主要的跨群組擴散點**
5. **關鍵時刻分享**：破產、壟斷達成、認購競標勝出時提供分享鉤子

戰報之所以可行，是因為資料層採事件溯源（見 [05-data-model.md](05-data-model.md)），整局的敘事素材本來就完整存著。

## 7. 商業模式

### 7.1 App 內購（主要）

透過 LINE Mini App 於 2025 年開放的 In-App Purchase，以及獨立網站的金流。

| 品項 | 性質 | 說明 |
|---|---|---|
| 角色造型／頭像部件 | 純外觀 | 參數化 SVG 組合，零美術成本 |
| 棋盤主題皮膚 | 純外觀 | CSS 變數切換 |
| 骰子特效 | 純外觀 | CSS 動畫 |
| 局內改名／自訂地標暱稱 | 便利 | |
| 額外 Standing Orders 欄位 | 便利 | 免費版 3 條、付費版 8 條 |
| 詳細戰報／數據儀表板 | 便利 | 局末的完整財務分析 |

**紅線：不賣數值。** 不賣起始資金、不賣骰子點數、不賣租金加成。一旦賣數值，「經濟共生」的信條就破了，而那是產品唯一的差異化。

### 7.2 品牌置入（次要但天花板高）

比廣告更貼近遊戲體驗的合作形式：

| 形式 | 說明 | 潛在客戶 |
|---|---|---|
| 贊助地標 | 某一格從「信義區」變成「XX 銀行信義分行」，附專屬事件卡 | 銀行 |
| 保險商品置入 | 遊戲內保險選項掛品牌 | 保險公司 |
| 進修課程冠名 | 季度事務的進修選項連結真實課程 | 教育機構 |
| 車輛品牌 | 季度事務的車款換成真實車型 | 車商 |
| 事件卡贊助 | 機會卡「你辦了 XX 卡，回饋 $3,000」 | 金融、電商 |

品牌置入的技術基礎是地圖的**槽位設計**（見 [03-map-system.md](03-map-system.md)）——贊助內容是資料，不是程式碼，業務簽約後由後台設定即可上線。

### 7.3 LINE 廣告分潤（機會財）

LINE Mini App 已開放 In-App Ads 分潤，可作為非付費用戶的變現補充。優先度最低，因為插入廣告會傷害「這是桌遊」的體驗。

## 8. 成功指標（v1）

| 指標 | 定義 | 目標 |
|---|---|---|
| 開局轉換 | 群組收到邀請卡 → 實際加入的比例 | > 40% |
| 日常型完局率 | 開了日常型局 → 撐到結束條件觸發 | > 35% |
| **日活躍行動率** | 當天**親自**行動的玩家比例（非 Standing Orders 託管） | **> 70%** |
| 競標參與率 | 有無主地可搶時，實際出價的比例 | > 50% |
| 戰報分享率 | 完局 → 分享到至少一個其他群組 | > 20% |
| 群組二次開局率 | 完一局後 7 天內同群組再開 | > 30% |

**日活躍行動率**是最重要的健康指標。若長期低於 50%，代表遊戲對玩家沒有吸引力、大家都靠託管過關，社交感就死了。

> 目標從 60% 上調到 70%，是因為非同步改制移除了「錯過時窗」這個結構性障礙——現在玩家可以在一天內任何時間行動，做不到就是內容問題，不是機制問題。

**競標參與率**是新機制的專屬指標。若偏低，代表玩家不理解或不在乎認購制，那整個日常型的互動核心就失效了。
